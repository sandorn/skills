---
name: moke:genre-show
description: Display details of a genre profile / 显示题材配置详情
---

<objective>
Display complete information about a specific genre profile, including all configuration and writing guidance.
</objective>

<process>
1. 读取指定题材的配置文件：
   - 从 `genres/{genreId}.md` 读取
   - 如果不存在，显示错误信息并列出可用题材

2. 解析 YAML frontmatter 和正文内容

3. 以结构化格式展示所有配置项

4. 显示题材的写作指导（正文部分）
</process>

## 输出格式

```
题材配置：玄幻 (xuanhuan)
═══════════════════════════════════════════════════════════

【基本信息】
  题材ID：xuanhuan
  题材名称：玄幻
  语言：zh (中文)

【章节类型】
  1. 推进章
  2. 布局章
  3. 过渡章
  4. 回收章
  5. 突破章

【疲劳词监控】
  震惊、不可思议、难以置信、竟然、居然、完全、彻底、瞬间、刹那、瞳孔骤缩

【系统配置】
  数值系统：✓ (有等级、积分等数值化系统)
  战力提升：✓ (有力量成长体系)
  时代考证：✗ (不需要历史/时代考证)

【节奏规则】
  战斗与修炼交替，每3-5章一个小高潮，每10-15章一个大突破

【爽点类型】
  • 境界突破
  • 功法习得
  • 战胜强敌
  • 获得宝物
  • 打脸反杀
  • 揭露天机

【审计维度】
  1,2,3,4,6,7,8,9,10,13,14,15,16,17,18,19,24,25,26

───────────────────────────────────────────────────────────────

【题材禁忌】
  • 修炼过程过于轻松，没有付出就有收获
  • 境界突破没有过程，直接"叮"的一声升级
  • 战力系统崩坏，前期设定后期忘
  • 用"震惊"等情绪标签代替场景描写
  • 主角光环过重，每次都毫发无伤

【玄幻规则】
  • 境界体系必须清晰：炼体 → 炼气 → 筑基 → 金丹 → 元婴 → ...
  • 每个境界有明确的实力差距，不同境界难以越级挑战
  • 修炼必须体现艰苦：打坐、炼丹、炼器、历练、生死试炼
  • 战斗描写：招式、能量碰撞、境界压制、法则感悟
  • 宝物系统：丹药、功法、灵石、法宝、天材地宝
  • 力量体系：灵力、神识、法则、道韵

【节奏指导】
  • 前期（1-50章）：快速建立世界观，主角频繁突破，建立爽点
  • 中期（51-150章）：战力稳定提升，引入更大势力，揭开世界真相
  • 后期（151-200+章）：巅峰对决，飞升成神，解答所有伏笔

  • 战斗场景要有层次：试探 → 激烈 → 绝境 → 反击 → 胜利/逃脱
  • 每次突破前必须有充分的铺垫：修炼过程、瓶颈压力、突破契机
  • 打脸要有铺垫：装逼 → 嘲讽 → 隐忍 → 爆发 → 震惊

【语言风格】
  • 动作描写要具体：不用"他攻击"，用"他一拳轰出，拳风撕裂空气"
  • 能量描写要有画面感：金光、血气、雷鸣、空间扭曲
  • 避免过度使用"震惊"等词，通过旁人的反应和场景细节体现
  • 战斗节奏快，但关键招式要慢镜头描写
```

## 使用方式

```bash
# 查看玄幻题材详情
/moke:genre-show xuanhuan

# 查看都市题材详情
/moke:genre-show urban

# 查看恐怖题材详情
/moke:genre-show horror
```
