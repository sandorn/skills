# MoKe 模板系统说明

本目录包含 MoKe（墨客）AI 小说写作系统的所有状态文件模板。

## 模板文件概览

### 1. moke.json
**用途**：书籍核心配置文件
**包含内容**：
- 书籍基本信息（ID、标题、类型）
- 目标设定（章节数、每章字数）
- 元数据（创建时间、更新时间）

**何时使用**：创建新书籍时必需

### 2. story_bible.md
**用途**：世界观设定文档
**包含内容**：
- 核心设定（世界类型、力量体系、地理环境）
- 主要势力
- 力量等级体系
- 特殊规则和禁忌

**何时使用**：
- 开始写作前必须完成
- 写作过程中持续补充和完善

### 3. current_state.md
**用途**：当前故事状态追踪
**包含内容**：
- 角色位置
- 角色关系
- 已知信息分布
- 当前冲突
- 资源状态

**何时使用**：
- 每章写作前更新
- 保持剧情逻辑一致性

### 4. hooks.md
**用途**：伏笔管理
**包含内容**：
- 已埋伏笔列表（含ID、状态、预期回收时间）
- 已回收伏笔记录
- 伏笔分类（主线/支线/彩蛋）

**何时使用**：
- 埋下新伏笔时立即记录
- 每章检查是否有可回收的伏笔
- 定期回顾，避免遗忘

### 5. summaries.md
**用途**：章节摘要记录
**包含内容**：
- 每章的简要摘要
- 主要人物、事件、伏笔
- 情感基调和预期读者反应

**何时使用**：
- 每章完成后立即记录
- 用于长期回顾和查找

### 6. volume_outline.md
**用途**：卷级大纲规划
**包含内容**：
- 每卷的核心目标和冲突
- 章节范围和规划
- 关键情节
- 伏笔规划

**何时使用**：
- 开始新一卷前规划
- 写作过程中调整和细化

## 工作流程建议

### 初始化阶段
1. 复制 `moke.json` 并填写书籍基本信息
2. 完成 `story_bible.md` 世界观设定
3. 规划第一卷大纲到 `volume_outline.md`

### 日常写作流程
1. **写作前**：
   - 更新 `current_state.md` 确认角色位置和状态
   - 检查 `hooks.md` 是否有需要回收的伏笔

2. **写作中**：
   - 参考 `story_bible.md` 保持世界观一致
   - 参考 `volume_outline.md` 按大纲推进

3. **写作后**：
   - 在 `summaries.md` 添加本章摘要
   - 如埋下新伏笔，在 `hooks.md` 中记录
   - 如回收伏笔，更新 `hooks.md` 状态
   - 更新 `current_state.md` 记录新状态

## 最佳实践

1. **及时更新**：不要依赖记忆，立即记录
2. **使用ID**：伏笔使用唯一ID（H001, H002...）便于追踪
3. **定期回顾**：每周回顾所有状态文件，检查不一致
4. **版本控制**：使用 Git 追踪状态文件变化
5. **保持简洁**：摘要和状态说明要简洁明了，避免过于详细

## 文件命名规范

在创建实际书籍时，建议的目录结构：
```
moke/
├── books/
│   └── [book-id]/
│       ├── moke.json
│       ├── story_bible.md
│       ├── current_state.md
│       ├── hooks.md
│       ├── summaries.md
│       └── volume_outline.md
└── templates/
    └── [模板文件]
```

## 常见问题

**Q: 如果大纲需要调整怎么办？**
A: 随时可以调整 `volume_outline.md`，同时在 `current_state.md` 中记录变更原因。

**Q: 伏笔可以废弃吗？**
A: 可以，在 `hooks.md` 中将状态改为"废弃"并记录原因。

**Q: 摘要应该多详细？**
A: 3-5句话概括主要事件即可，详细内容看正文。

**Q: 需要同时维护多本书吗？**
A: 每本书有独立的 `[book-id]` 目录和完整的状态文件。
