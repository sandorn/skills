# Code — 代码与文档

## 子类型

### 代码审查 (code-review-skill)

多语言多框架审查：React/Vue/Angular/Svelte/Rust/TypeScript/Java/Python/Go/C#/Kotlin/C/C++。

- 五级努力度：low/medium/high/max/xhigh
- 9 角度分析 + 验证 + Sweep
  触发：code review、PR review、review code、审查

### 文档写作 (doc-coauthoring)

结构化三步流程：上下文收集 → 细化结构 → 读者测试。
触发：写文档、draft proposal、PRD、design doc、decision doc、RFC

## 选择指南

- 代码改动 → code-review
- 写设计/技术文档 → doc-coauthoring
