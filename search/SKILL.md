# Search — 学术搜索

## 搜索源

| 源 | 用途 | 触发词 |
|----|------|--------|
| arxiv | 预印本搜索/下载 | arxiv search、download paper |
| semantic-scholar | 正式发表论文，含引用计数 | find IEEE papers、journal papers |
| alphaxiv | LLM 优化摘要，快速理解 | explain this paper、summarize |
| openalex | 开放引用图，机构/基金信息 | openalex search、citation graph |
| exa-search | 广泛互联网搜索 | exa search、web search |
| gemini-search | AI 驱动的文献发现 | gemini search、AI search |

## 选择指南
- 预印本 → arxiv
- 已发表论文 → semantic-scholar
- 快速了解论文 → alphaxiv
- 引用/机构分析 → openalex
- 跨学科宽搜 → exa-search / gemini-search
