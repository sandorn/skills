# 网文剧情触发库

> Layer 3 软性优化建议。提供网文写作中常见的剧情触发模式和节奏模板。Claude CLI 按需引用，不强制硬性约束。

---

## 一、升级冲突触发模式

### 1.1 被动突破
- **触发条件**: 生死危机 → 绝境求生 → 瓶颈松动
- **节奏**: 危机（70%）→ 挣扎（15%）→ 灵光一闪（5%）→ 突破（10%）
- **视觉锚点**: 灵气漩涡、天象异变、瓶颈碎裂声

### 1.2 丹药/机缘突破
- **触发条件**: 获得稀有资源 → 闭关 → 突破
- **节奏**: 获得（20%）→ 准备（30%）→ 冲击（40%）→ 突破+异象（10%）
- **视觉锚点**: 丹药入口化气、经脉冲刷、丹田扩张

### 1.3 战斗突破
- **触发条件**: 势均力敌 → 战斗中领悟 → 临阵突破
- **节奏**: 劣势（50%）→ 死战不退（20%）→ 一念通达（10%）→ 反杀（20%）
- **关键**: 突破不能廉价——必须有铺垫（战前已接近瓶颈）

## 二、反转铺垫模式

### 2.1 信息差反转
- **模式**: 读者/主角已知信息 ≠ 反派已知信息
- **效果**: 主角"误入"陷阱实则将计就计
- **铺垫要求**: 前文 3-5 章埋一个貌似无用的信息点

### 2.2 隐藏底牌
- **模式**: 看似败局已定 → 底牌揭晓 → 扭转
- **铁律**: 底牌必须在前文中出现过（不能凭空出现）
- **经典底牌**: 法器、禁术反噬、援军、环境利用

### 2.3 身份反转
- **模式**: 看似弱者/叛徒/路人 → 实则强者/卧底/关键人物
- **铺垫**: 3 处以上细小反常行为

## 三、人物登场模板

### 3.1 强者登场
- **模式**: 先声夺人 → 气场压制 → 辨识度特征 → 身份揭示
- **辨识度**: 独特称呼、标志性法器、口头禅、外形特征

### 3.2 神秘人登场
- **模式**: 只闻其声/只见其影 → 局部特征 → 关键信息抛出 → 消失
- **后续钩子**: 留下一个未解之谜

### 3.3 日常角色出场
- **模式**: 场景刻画 → 角色当前状态 → 对话互动 → 推进剧情
- **每出场必有目的**: 推进剧情 OR 展示角色面 OR 埋信息

## 四、打斗场面结构

### 4.1 标准战斗节奏
```
探查期（10%）: 双方评估实力，试探攻击
交锋期（30%）: 常规手段交锋，展示战力体系
转折期（30%）: 一方出奇招/底牌，打破平衡
高潮期（20%）: 决定性一击
收尾期（10%）: 战后状态、战利品、信息
```

### 4.2 群战结构
```
战前对峙（15%）→ 先手开团（15%）→ 混战（40%）→ 关键对决分离（20%）→ 战后结算（10%）
```

### 4.3 战力描写原则
- 同境界: 功法克制 > 战斗经验 > 装备差距
- 跨小境界（1-3级）: 弱方可凭底牌/技巧/环境争取
- 跨大境界: 必须有充分理由（禁术/阵法/器灵/自残式爆发）

## 五、章末钩子类型

### 5.1 死亡提问
- "他不知道的是……"
- "如果他知道接下来会发生什么，他绝不会……"
- **铁律**: 下一章必须回答这个问题

### 5.2 威胁逼近
- 新的敌人出现/旧敌增强
- 限时任务启动
- 隐藏危险线索

### 5.3 信息悬念
- 关键信息只揭示一半
- 新发现推翻旧认知
- 身份/真相局部揭示

### 5.4 情感钩子
- 牺牲/告别/重逢
- 背叛/信任危机
- 承诺/誓言

## 六、情绪过渡模板

| 过渡方向 | 技巧 | 示例 |
|---------|------|------|
| 胜利→损失 | 胜利场面后切入代价揭示 | "赢了，但……" |
| 压抑→释放 | 长时间压抑后用一个微小但明确的动作释放 | "他缓缓放下剑" |
| 温情→危机 | 温馨场景中插入一个不和谐的细节 | "茶还热着，人已经不在了" |
| 失败→觉醒 | 失败是触发成长的开关 | "没有退路了，只能……" |
| 日常→冲突 | 日常节奏突然被打断 | "就在这时……" |

---

## 七、过渡章节识别关键词

用于润色开关自动判定。当大纲中包含以下关键词时，可能触发"跳过润色":
- **移动类**: "前往" "赶路" "飞行" "传送" "出发" "抵达"
- **日常类**: "修炼" "休整" "采购" "整理" "疗伤" "闭关"
- **纯信息**: "回忆" "说明" "讲解" "设定" "旁白"
