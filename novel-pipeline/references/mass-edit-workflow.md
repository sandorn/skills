# 批量章节编辑工作流

> **适用范围**：跨章修为统一、批量伏笔植入、全局名词/称呼替换（**剧情/设定层**的批量修改）
> **与 `batch-format-fix.md` 的分工**：
> - 本文 → 剧情/修为/称呼/伏笔的**跨章统一**
> - batch-format-fix.md → 引号/破折号/AI 高频词等**格式层**修复
> 两者用同一套"Python 脚本原地替换、幂等、备份先行"的技术骨架，仅关注点不同。

## 核心原则

- **不做大幅修改**：220 章长篇小说投入巨大，追求完美一致性不如接受自然的不一致
- **选择性编辑**：只修影响读者理解的硬伤（如主线修为矛盾），保留叙事手法带来的表象出入（如敛息术伪装修为）
- **优先用 Python 脚本，不用 patch 工具**

## 为什么不用 `patch` 工具

在中文 `.md` 章节文件上，`patch` 工具反复失败的原因：

| 失败原因 | 表现 | 解决方案 |
|---------|------|---------|
| `\r\n` 编码 | 多行 old_string 不匹配 | Python `read/write` 自动处理 |
| 弯引号 vs 直引号 | `"` vs `"` 不相等 | Python `str.replace` 逐字符匹配 |
| Windows 文件锁 | 编辑后文件被外部修改 | 整文件写回（read→modify→write） |

**可靠工作流**：

```
1. write_file → 创建 .py 脚本
2. terminal → python .py 脚本
3. terminal → python -c "验证" 
4. Remove-Item .py
```

## 修为统一脚本模板

```python
# -*- coding: utf-8 -*-
"""
修为统一脚本
策略：
  - 如果某个突破在原文中真实发生了（如 ch36 筑基），保留
  - 后续章节中的旧修为引用（如 ch41 写"练气八层"）改为新修为
  - 只改主角自身修为描述，不改其他角色的正常描述
"""
import os, glob

BASE = r'D:\Writer\novel-project\chapters'
for fn in glob.glob(f'{BASE}\\ch*.md'):
    with open(fn, 'r', encoding='utf-8') as f:
        c = f.read()
    
    # 逐个替换，每个替换先 assert 确认存在
    patches = [
        ('旧字符串', '新字符串'),
    ]
    for old, new in patches:
        if old in c:
            c = c.replace(old, new)
    
    with open(fn, 'w', encoding='utf-8') as f:
        f.write(c)
```

## 修为级联修复决策框架

当主角在某一章提前突破（如 ch36 筑基），但后续 180 章仍以旧修为描述时，按以下优先级决策：

```
用户反馈:「后期修为必须提高，否则没有读者会看」
         ↓
    保留突破（✅ reader satisfation > consistency purity）
         ↓
    接受后续行文中的旧修为引用
         ↓
    原因：1) 敛息术伪装是常见写作手法
          2) 天墟之力爆发后的修为回落是核心战斗机制
          3) 全量回滚的工作量远超收益
```

**实际案例——ch36 突破筑基决策**：

| 选项 | 工作量 | 副作用 | 选择 |
|------|--------|--------|------|
| A: 回滚 ch36，恢复练气八层 | 1 章 | 主角 200 章不晋升，读者流失 | ❌ |
| B: 改 ch37-220 全部为筑基初期 | ~130 章 | 大量敛息术伪装描写需重写 | ❌ |
| C: **保留 ch36 突破，接受旧修为引用为敛息术** | 0 章 | 少量不一致但读者不察觉 | ✅ |

**结论**：对 200+ 章的长篇小说，全量统一的代价远高于收益。敛息术、伪装类写法天然会产生明面修为与真实修为的不一致，这是叙事手法而非错误。

长篇小说（200+ 章）的修为设定天然存在不一致，以下策略可接受：

- **敛息术伪装**：主角对外显示低修为是常见写法，不视为设定错误
- **天墟之力回落**：爆发后修为临时下跌是合理的剧情需要
- **基准修炼 + 临时爆发**：金丹基准 + 天墟之力临时提升至元婴/化神，是本书的核心战斗机制
- **不做全量回滚**：如果某个突破（如 ch36 筑基）与后续 180 章的行文矛盾，保留突破、接受后续行文中的旧修为引用作为敛息术表现
