# 公文写作 — 质量检查清单

将下列检查项作为发文前的必检项（可转为 checklist 表单）。

## 格式检查

- [ ] 标题、主送机关、正文、结尾、落款、日期齐全
- [ ] 段落层次（总—分—总）清晰

## 内容检查

- [ ] 依据是否列明或标注为待核实
- [ ] 关键数据是否可追溯并标注来源
- [ ] 附件是否齐全并能打开

## 逻辑检查

- [ ] 观点—事实—结论链条完整
- [ ] 因果关系清晰，无自相矛盾

## 语言检查

- [ ] 无口语化、无模糊词、无情绪化表达
- [ ] 单句长度适中（建议≤40字）

## 合规与政策检查

- [ ] 政策用语规范，与集团/市级文件对标
- [ ] 无敏感措辞

## 交付检查

- [ ] 待确认项已列出并指定负责人与时限
- [ ] 导出到 docx/pdf 的模板及文件名符合规范

> 使用说明：可将此文件转为 Excel/CSV 表单，用于线下或 OA 审核。
