## 一、请示完整示例

### 关于申请追加2026年度信息化建设预算的请示

```markdown
# 关于申请追加2026年度信息化建设预算的请示

XX集团有限公司：

根据《XX集团2026年度信息化建设规划》（XX〔2026〕XX号）要求，我司原计划实施ERP系统升级改造项目，预算总额为XX万元。因项目实施过程中发现原有系统架构老化程度超出预期，需增加数据迁移和安全加固模块，导致项目成本增加。

一、追加预算的理由

（一）系统架构老化超出预期。经XX公司技术评估，原有系统架构已运行XX年，数据迁移难度较原计划增加XX%，需增加专业数据清洗工具和人工成本。

（二）安全合规要求提升。根据《网络安全法》及XX部门最新要求，系统需达到等保三级标准，需增加安全加固模块，预计增加成本XX万元。

（三）业务需求扩展。因业务发展需要，新增XX个业务模块，需相应增加系统开发成本XX万元。

二、追加预算事项

（一）追加金额：XX万元。
（二）资金来源：从XX科目调剂解决XX万元，申请集团拨付XX万元。
（三）使用计划：追加预算主要用于数据迁移XX万元、安全加固XX万元、新增模块开发XX万元。

三、建议方案

建议同意追加预算XX万元，其中XX万元由集团拨付，XX万元由我司自行调剂解决。

妥否，请批示。

附件：1. ERP系统升级改造项目追加预算明细表2. XX公司技术评估报告

XX有限公司
2026年X月X日

## 待确认事项

- [ ] 集团公司全称
- [ ] 原预算金额
- [ ] 系统运行年限
- [ ] 数据迁移难度增加比例
- [ ] 安全加固成本
- [ ] 新增模块数量及成本
- [ ] 追加总金额
- [ ] 资金来源具体科目

```

**关键要素**：依据段→理由段→事项段→建议方案→规范结尾"妥否，请批示"。

## 五、建议书完整示例

### 关于优化子公司绩效考核机制的建议书

```markdown
# 关于优化子公司绩效考核机制的建议书

集团公司领导：

为深入贯彻落实国企改革深化提升行动要求，进一步完善子公司绩效考核机制，激发经营活力，提升发展质量，结合当前考核工作实际，现提出如下建议：

一、现状与问题

（一）考核指标设置不够科学。部分指标与战略目标衔接不紧密，存在"重结果轻过程"现象。
（二）考核周期相对单一。目前实行年度考核，缺乏季度、月度过程管控。
（三）激励约束机制不够完善。考核结果与薪酬分配、干部任用挂钩不够紧密。
（四）考核主体较为单一。主要由集团考核子公司，缺乏多维度评价。

二、优化建议

（一）优化指标体系。建议建立"战略引领+分类考核+差异化权重"的指标体系。根据子公司业务特点，如酒店类重点考核入住率、RevPAR，地产类重点考核去化率、回款率。
（二）完善考核周期。建议实行"月度监测+季度评估+年度考核"相结合的方式。
（三）强化结果运用。考核结果为"优秀"的绩效薪酬上浮XX%，"不合格"的下调XX%；连续两年不合格的调整主要负责人。
（四）引入多元评价。建立"上级评价+同级评价+职工评价+第三方评价"的多元评价机制。

三、预期效果

（一）提升战略执行力。引导子公司聚焦主责主业，确保集团战略目标落地。
（二）增强经营活力。激发子公司经营积极性，预计可提升利润总额XX%以上。
（三）提高管理效能。实现过程管控，及时发现和解决问题，降低经营风险。

以上建议请审阅。

XX部门
2026年X月X日
```

**关键要素**：背景目的 → 现状问题分析 → 具体建议（含可行性） → 预期效果 → "以上建议请审阅"。

## 六、提示函完整示例

### 关于提示做好安全隐患整改工作的函

```markdown
# 关于提示做好安全隐患整改工作的函

XX公司：

根据集团安全生产检查工作安排，检查组于2026年X月X日对你公司安全生产管理情况进行了现场检查。检查发现，你公司在消防设施维护、应急预案演练、隐患台账管理等方面仍存在薄弱环节。为进一步压实安全生产主体责任，现就有关事项提示如下：

一、提示事项

（一）消防设施维护不到位。部分灭火器存在巡检记录不完整、摆放位置不规范等问题，需及时核查并整改。

（二）应急预案演练不充分。年度演练计划执行进度滞后，相关岗位员工对应急处置流程掌握不够熟练。

（三）隐患整改台账不完善。部分隐患事项未明确整改责任人、完成时限和复核结果，闭环管理要求落实不到位。

二、有关要求

（一）提高思想认识。请你公司高度重视安全生产工作，严格落实安全生产主体责任，坚决防范各类安全事故发生。

（二）立即组织整改。对检查发现的问题逐项制定整改措施，明确责任部门、责任人和完成时限，确保问题整改到位。

（三）健全长效机制。进一步完善日常巡检、隐患排查、应急演练等制度，推动安全管理由被动整改向主动防控转变。

三、反馈要求

请你公司于2026年X月X日前将整改落实情况、整改台账及相关佐证材料报送XX部门。联系人：XX，电话：XX。

特此函告，请予重视。

XX有限公司
2026年X月X日

## 待确认事项

- [ ] 主送公司名称
- [ ] 检查日期
- [ ] 具体隐患事项
- [ ] 整改反馈截止日期
- [ ] 报送部门、联系人及电话
- [ ] 发文机关和发文日期
```

**关键要素**：依据和背景 → 提示事项 → 整改要求 → 反馈时限 → “特此函告，请予重视”。
