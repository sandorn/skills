# 常见故障排除

---

## 写章时

| 症状 | 原因 | 解决 |
|------|------|------|
| 初稿字数 1500-2200 | 句短低估了实际字数 | 初稿瞄准 3200+；写到 60% 处检查 |
| 「不是…而是…」反复出现 | 英语 "not X but Y" 思维惯性 | 写完先 grep，命中则逐句改 |
| delegate 返回但质量差 | max_iterations 不够 | 单批 ≤5 章；context 必须含完整禁令 |
| write_file 后文件含 `\"` | JSON 转义残留 | 全文用「」不用 `""` |

## 审查时

| 症状 | 原因 | 解决 |
|------|------|------|
| audit.py 报 "不是文件也不是目录" | 路径不存在 | 检查 `chapters/` 目录是否存在 |
| fact_db.py query 返回空 | facts.db 未初始化 | `python scripts/fact_db.py init .` |
| 段落超标始终修不完 | 用 `echo >>` 追加了内容 | 禁止 echo >>；统一用 pad_chapter.py |
| 模板复制 S1 反复出现 | 字数追加时复用了同一段白描 | pad_chapter.py v6 已内置去重 |

## 委派时

| 症状 | 原因 | 解决 |
|------|------|------|
| 子Agent 返回"已修复"但实际未修 | patch 静默失败 | 主会话抽样验证；机械修复不委派 |
| 多章章末完全相同 | echo >> 模板复制 | 禁止 echo >>；pad_chapter.py 逐章独特收尾 |
| 子Agent 违反禁令 | context 未含完整禁令清单 | context 显式列出全部 P0 禁令 |

## 修复时

| 症状 | 原因 | 解决 |
|------|------|------|
| sed 替换导致语句断裂 | 只删词不调句 | sed 仅用于破折号；AI 句式走逐句 patch |
| split_paragraphs 后段落反而更多 | 拆分后未检查连贯性 | 拆分后通读一遍确认 |
| pad_chapter 后字数仍不足 | 全文已饱和 | 在章末场景追加 1-2 段配角反应/环境过渡 |
