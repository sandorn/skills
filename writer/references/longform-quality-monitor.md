# 长篇质量趋势监控

> **适用范围**：长篇写作 >100 章后的跨章节质量趋势分析（声音漂移/情绪单调/风格指纹）。**不适用**：<100 章的项目——单章审查即可覆盖。
> **加载时机**：每写完一卷(≥60章)或达到 100 章里程碑时。**非日常审查**。

---

## 一、角色声音漂移检测

### 问题

写 200 章后，主角/核心配角的对话风格可能不知不觉改变：句长变了、口头禅丢了、语气从冷淡变成话多。

### 检测方法

每隔 50 章（或每卷末），对每个核心角色执行以下采样对比：

```
采样：ch01 / ch50 / ch100 / ch150 / ch200 中各取 3 段该角色的对话
对比维度：
  ① 平均句长（汉字数/对话句数）
  ② 语气词密度（吧/呢/啊/哈/嘛 每百字次数）
  ③ 称呼习惯（对同一人的称呼是否变化）
  ④ 口头禅/标志性句式（是否出现/消失）

判定：
  任一维度偏差 >30% → S2 警告「角色声音漂移」
  偏差 >50% → S1 阻塞「角色声音严重漂移」
```

### 操作步骤

1. 在 `tracking/` 下创建 `voice_samples.md`
2. 每个采样点粘贴 3 段该角色对话（每段 50-100 字）
3. 人工目测对比，或让 AI 做句长统计
4. 记录偏差值，标注趋势方向（越来越长/越来越短/越来越口语/越来越书面）

## 二、情绪节奏单调检测

### 问题

连续 N 章同类型情绪（如连续 6 章"爽"），读者产生审美疲劳。当前维度 13 只看主角情绪，不看**章级情绪类型分布**。

### 检测方法

每写完 10 章，统计这 10 章的情绪类型分布：

| 情绪类型 | 标签 | 适用场景 |
|---------|------|---------|
| 爽 | 装逼/打脸/碾压/获得奖励 | 核心爽点章 |
| 紧张 | 战斗/博弈/倒计时/危机 | 冲突升级章 |
| 期待 | 伏笔揭示/新线索/预告 | 悬念铺垫章 |
| 温情 | 日常/感情线/团队羁绊 | 过渡调节章 |
| 反转 | 真相揭晓/立场颠覆/身份暴露 | 高潮章 |

### 判定规则

```
连续 3 章同类型 → S3 信息提示「情绪单调风险」
连续 5 章同类型 → S2 警告「情绪单调，建议插入调节章」
连续 8 章同类型 → S1 阻塞「情绪严重单一，读者大概率疲劳」
```

### 与现有工具的关系

`analyze_rhythm.py --dim emotion` 可实现章级情绪类型标注。若 rhythm 脚本未实现此维度，主会话可手工标注。

## 三、写作风格指纹监控

### 问题

随着写作推进，AI 辅助写出的章节可能与前期手动/不同 AI 写出的章节在风格上缓慢偏离——句长分布、感官密度、对话占比逐卷变化。

### 基准采样

在 ch01-10 建立"风格指纹"基准：

```
从 ch01-10 中随机抽 3 章，每章随机抽 500 字正文（排除对话），统计：

  ① 平均句长：总汉字数 / 句号数
  ② 句长方差：句长的标准差
  ③ 感官词密度：视觉/听觉/触觉/嗅觉词 每千字次数
  ④ 对话占比：对话字数 / 全章字数
  ⑤ 段落平均长度：全章汉字数 / 段落数
  ⑥ 动作词密度：动词 每千字次数

→ 这 6 个数字构成"风格指纹 v1"
```

### 定期采样

每 50 章（或每写完一卷），对最新 10 章做同样的 6 维采样：

```
对比基准指纹 vs 当前指纹：
  任一维度偏差 >25% → S3「风格漂移提示」
  任一维度偏差 >40% → S2「风格显著漂移」
  ≥3 个维度偏差 >25% → S2「风格系统性漂移」
```

### 操作

- 风格指纹存储到 `tracking/style_fingerprint.md`
- 每次采样追加一条记录
- 不需要脚本——主会话用肉眼抽样+估算即可
