# 写前 30 秒检查清单

> 写每章前花 30 秒过一遍。初稿质量从源头提升，减少事后返工。

---

## 必答三问

写任何一章前，脑中明确回答：

```
Q1: 本章爽点是什么？
    → 能一句话指出：{具体爽点}
    → 放在什么位置？前/中/后

Q2: 章末钩子是什么类型？
    → 悬念/反转/威胁/期待/未完成动作/倒计时
    → 钩子句是否已经想好？

Q3: 本章禁区是什么？
    → 检查 hard-bans.md P0 5 条，本章有没有容易踩的？
```

## 上下文四查

### 1. 角色起点（从哪里开始？）

- 主角当前：等级 / 位置 / 金币 / 情绪状态
- 本章出场的配角当前状态
- 方法：扫一眼 `tracking/current_state.md` 或 `追踪/角色状态.md`

### 2. 伏笔包袱（有什么要回收/推进/新埋？）

- 待回收伏笔：这一章能不能收一个？
- 需推进伏笔：这一章能不能暗示一下？
- 新埋伏笔：这一章要不要埋新坑？
- 方法：扫一眼 `tracking/hooks.md` 或 `追踪/伏笔.md`

### 3. 大纲锚点（本章在大纲里的位置？）

- 本章对应大纲里的哪个核心事件？
- 在节拍表的哪个区间？启/承/转/合？
- 上一章结尾的情绪是什么？本章情绪要不要变化？
- 方法：扫一眼 `outline/chapter_outline/ch_{NNN}.md`

### 4. 时间线（本章发生在什么时间？）

- 与上一章间隔多久？
- 是否需要明确标注时间跳转？
- 方法：看上一章章末的时间锚点

## 章末钩子检查

写完全章后，问自己：读者读完最后一句话，会不会想翻下一章？

| 钩子类型 | 检查 |
|---------|------|
| 悬念钩 | 抛出的问题读者能一句话复述吗？ |
| 反转钩 | 新信息是否真的颠覆了前面的认知？ |
| 威胁钩 | 危机是否紧迫到必须下一章解决？ |
| 期待钩 | 预告的事件读者真的在期待吗？ |

如果以上四种都不是 → 章末钩子不合格，补。

## 快速禁令自查（写完后 10 秒）

```
□ 对话全用「」了？
□ 没有「——」？
□ 没有「他知道」「忽然」「似乎」「仿佛」？
□ 字数 ≥2500？
```

任一否 → 修完再提交。
