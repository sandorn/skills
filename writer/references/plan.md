# 大纲规划：总纲→卷纲→章纲

---

## 执行原则

1. **只做增量补齐，不重写整份总纲或设定集。**
2. **先锁定卷级节奏，再批量拆章。**
3. **时间线是硬约束，所有章纲必须带时间字段。**
4. **若发现总纲与设定冲突，先阻断，再等用户裁决。**
5. 优先级链：用户明确要求 > 总纲核心冲突与卷末高潮 > 时间线硬约束 > skill 默认流程。

---

## Step 0：读取现有项目状态

- 读取 `writer.json`，确认 project/stage/chapters_done 等
- 读取 `outline/master_outline.md` 或 `大纲/` 下总纲/卷纲，确认核心冲突、结局方向
- 读取 `outline/volume_outline.md` 或 `大纲/卷纲*.md`（如有），确认当前卷号

---

## Step 1：确认规划范围

用 `clarify` 确认；用户已给出的范围不要重复问：

- **规划第几卷？**（默认当前卷或下一卷）
- **总章节数范围？**（如：第1-30章）
- **是否有特殊要求？**（如：需要加入节日线、时间跳跃等）

---

## Step 2：卷级设计

生成卷级结构（写入 `outline/volume_outline.md` 或旧结构 `大纲/卷纲_vX.md`）：

### 卷头信息

```markdown
## 第{N}卷：{卷名}

- 章节范围：第 X 章 - 第 Y 章
- **本卷目标**：主角在本卷结束时达到什么状态
- **爽点节奏**：每 N 章一个大爽点
- **情绪弧线**：本卷整体情绪走向
- **人物弧线**：主要角色在本卷的成长/变化
- **伏笔布局**：本卷埋设的伏笔及计划回收时间
- **关键反转**：本卷至少一个关键反转
- 时间跨度：
```

### 节拍表

| 阶段 | 章节范围 | 核心事件 | 情绪目标 | 备注 |
|------|---------|---------|---------|------|
| 启 | 1-? | 引入/铺垫 | 好奇心/期待 | |
| 承 | ?-? | 发展/升级 | 爽感/紧张 | |
| 转 | ?-? | 冲突升级/转折 | 紧张/震撼 | |
| 合 | ?-? | 高潮/回收 | 释放/满足 | |

### 时间线（硬约束）

| 章节 | 时间点 | 事件 | 备注 |
|------|--------|------|------|
| 1 | 第一天上午 | | |
| 2 | 第一天下午 | | |
| ... | | | |

## Step 3：章纲批量拆分

### 章纲格式

每章章纲格式：

```markdown
## 第{N}章：{章名}

- **时间：** {时间点}
- **字数目标：** 3000
- **核心事件：** [一句话]
- **情绪目标：** [爽/紧张/反转/温情]
- **情绪变化：** {起点}→{终点}（不得与上一章相同）
- **章首钩子类型：** [悬念对话/闪前碎片/倒计时开局/神秘独白/反差场景/未完成动作/意象预示]
- **主要场景：**
  1. [场景1]
  2. [场景2]
- **本章爽点/情绪节点：**
- **必须包含：**
  - [关键元素]
- **必须避免：**
  - [禁区]
- **伏笔操作：** 埋伏/推进/回收
- **章末钩子类型：** [突然揭示/紧急危机/未完成动作/身份反转/两难抉择/神秘物品线索/倒计时/承诺威胁/离奇消失/隐藏含义/意象钩子/回声钩子/留白钩子]
- **涉及角色：**
```

保存到 `outline/chapter_outline/ch_{NNN}.md`。旧中文结构可保存到 `大纲/章纲/ch_{NNN}.md` 或沿用现有大纲文件组织方式。

---

## Step 4：验证

- [ ] 卷纲包含全部必填项（目标/爽点节奏/情绪弧线/人物弧线/伏笔布局/关键反转）
- [ ] 时间线连续无回跳（闪回例外）
- [ ] 每个章纲字数目标明确
- [ ] 每章章纲有核心事件
- [ ] 每章章纲有情绪变化（不连续2章相同）
- [ ] 每章章纲有章首钩子（从7种类型中选择）
- [ ] 每章章纲有章尾钩子（从13种类型中选择）
- [ ] 章节不重叠、不跳号

**阻断条件触发**：标记 BLOCKER，等待用户裁决再继续。

## 批量拆章参考

### 节奏模板

| 章节位置 | 建议节奏 | 说明 |
|---------|---------|------|
| 第1章 | 快速钩子 | 300字内交代主角+钩子 |
| 第2-3章 | 金手指亮相 | 展现核心吸引力 |
| 第4-5章 | 第一次冲突 | 展现实力/智商 |
| 第6-10章 | 展开世界观 | 引入势力+配角 |
| 每10章 | 小高潮 | 回收小伏笔+设置新钩子 |
| 每卷末 | 卷高潮 | 大冲突+强力钩子 |

### 情绪周期

```
爽 → 期待 → 紧张 → 爽 → 意外 → 爽
```
避免连续 3 章同类型情绪输出。
