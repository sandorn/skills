# 污染修复参考：「不→是」及变体

> 最后更新：2026-06-28，《网游具现》46章逐章审查后
> 触发场景：子代理批量写章返回后，或运行过全局文本替换脚本后

## 污染来源

子代理返回后，主会话运行批量修复脚本（替换 AI 高频词、修复 B03 句式）时，宽松的 `str.replace` 或正则可能误伤中文「不」字，将其替换为「是」，产生大范围文本污染。

典型触发：修复脚本中 `text.replace('不是', '是')` 或类似的无上下文替换。

### 假阳性（不可自动修复，需上下文判断）

| 模式 | 说明 |
|------|------|
| `是不是` | 疑问句式，合法 |
| `不是…。是…。` | 句号断开，B03 合规 |
| `不是…但…` | 转折结构，非 B03 禁止 |
| `不是…就是…` | 选择句式，合法 |

## 扫描脚本

```python
import re, os

root = "chapters"
corrupt_patterns = [
    '是疼','是胀','是错','是到','是敢','是急','是能','是像','是起',
    '是懂','是够','是怕','是对劲','是知道','是同意','是正常','是清楚',
    '是舍得','是靠谱','是消停','是声张','是炫耀','是照旧'
]

for fn in sorted(os.listdir(root)):
    if not fn.endswith('.md'): continue
    with open(os.path.join(root, fn), 'r', encoding='utf-8') as f:
        text = f.read()
    hits = [p for p in corrupt_patterns if p in text]
    if hits:
        print(f'{fn}: {hits}')
```

## 修复方法

逐字替换，禁用宽松正则。每次替换后验证计数器归零。

### ⚠️ 批量修复脚本二次污染（新增）

**永远不要对含「不」字的文本使用全局替换脚本。** 修复脚本使用 `text.replace('不是', '是')` 或类似无上下文逻辑，会导致二次污染：

```
原始：「不是怕。是沉。」
→ 第一轮修复（宽松正则）：「是怕。是沉。」
→ 第二轮修复（再次扫描「是怕」→「不怕」）：「不不怕。是沉。」  ← 二次污染！
```

**教训**：
- 禁止 `re.sub(r'不是', '是', text)` 类的全局替换
- 禁止 `text.replace('不', '')` 先删再补的操作
- 所有「不→是」修复必须逐上下文判断，确认语义后再替换
- 修复后运行验证脚本确认无「是是」「不不怕」等二次污染模式
