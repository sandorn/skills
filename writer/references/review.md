# 审查：统一 43 维质量审计

改编自 Moke 37 维审计 + story-review 多模式 + webnovel-review JSON 指标落库。

---

## 核心原则

1. **审查是找问题，不是验证正确性。** 每一轮审查都必须找到可改进的点。
2. **维度全面，但不滥打。** 默认 solo 模式检查最主要的 15 项；full 模式跑全 43 维。
3. **blocking issue 必须修复，info 级只记录不阻断。**
4. **冲突分级 S1-S4：** S1=直接矛盾必须修复，S2=隐性矛盾建议修复，S3=细节不一致提示，S4=潜在风险记录。所有审查报告按此分级输出。

---

## 模式选择

| 模式 | 命令 | 说明 |
|------|------|------|
| **solo（默认）** | `review` | 当前会话内执行，15 项核心维度 + AI 痕迹 + 硬禁令 |
| **lean** | `review --lean` | 当前会话内，27 项基础维度 + AI 痕迹 + 硬禁令 |
| **full** | `review --full` | 优先 delegate_task spawn 子Agent，全 43 维 + 风格审查；不可用时降级 lean/solo |
| **quick** | `review --quick` | 纯规则扫描，0 token 消耗。仅执行禁令扫描 + 格式检查 + 字数统计，依赖 bin/ 脚本或内联 Python 规则，不涉及 AI 推理 |

---

## 模式详解

### quick 模式

不 spawn 任何 Agent，不消耗 token。纯机械检查：

1. **禁令扫描**：破折号 / 不是…而是… / 元叙事 / 分析术语 / AI高频词
2. **格式检查**：段落按句号断段，每段15-40汉字
3. **字数统计**：是否 ≥ 2000 汉字
4. **模板复制检测**：连续3章相同开篇句式

输出纯违规清单，无 AI 分析、无修改建议。适合高频自检。

```bash
# 等效脚本命令
grep -c '——' chapters/ch_*.md
grep -c '不是.*而是' chapters/ch_*.md
grep -cnE '忽然|深吸一口气|眼中闪过|他知道' chapters/ch_*.md
```

## 审查维度（统一 43 维）

### 核心维度（15 项，solo 模式必检）

| 编号 | 维度 | 说明 | 阈值 |
|------|------|------|------|
| 1 | **OOC检查** | 角色行为是否符合性格底色 | 偏离必须有情境驱动 |
| 2 | **时间线检查** | 时间顺序是否合理 | 无回跳（闪回例外） |
| 3 | **设定冲突** | 是否违反世界观设定 | 零容忍 |
| 4 | **战力崩坏** | 战斗力是否合理 | 无突然跳升/降 |
| 5 | **伏笔一致性** | 新伏笔记录/旧伏笔推进 | 每章至少检查 |
| 6 | **节奏** | 叙事节奏是否单调 | 连续3章相同类型 warning |
| 7 | **文风一致性** | 风格是否符合题材 | 明显断裂 warning |
| 8 | **信息越界** | 角色知道不该知道的信息 | 零容忍 |
| 9 | **台词失真** | 对话是否符合人物身份 | 明显异常 blocking |
| 10 | **流水账** | 是否只有事件罗列 | 3处以上 warning |
| 11 | **视角一致性** | 视角切换有过渡 | 突然切换 blocking |
| 12 | **支线停滞** | 支线是否超过5章未推进 | ≥5章 warning |
| 13 | **弧线平坦** | 主角情绪连续3章无变化 | ≥3章 warning |
| 14 | **章末钩子** | 章尾是否有追读驱动力 | 缺失 → info |
| 15 | **字数合规** | 是否达到目标字数 | ±200字 warning |

### 扩展维度（12 项，lean 模式追加）

| 编号 | 维度 | 说明 |
|------|------|------|
| 16 | 数值检查 | 等级/资源/属性连续 |
| 17 | 词汇疲劳 | 高疲劳词密度（每3000字≤1次） |
| 18 | 利益链断裂 | 角色动机充分性 |
| 19 | 年代考据 | 真实年代细节准确 |
| 20 | 配角降智 | 配角是否不合理降智 |
| 21 | 配角工具人化 | 配角缺乏独立性 |
| 22 | 爽点虚化 | 爽点是否清晰有力 |
| 23 | 知识库污染 | 引入不合理外部知识 |
| 24 | 读者期待管理 | 近3-5章有爽点落地 |
| 25 | 大纲偏离 | 是否偏离大纲核心冲突 |
| 26 | 伏笔紧急度 | 有未回收的紧急伏笔？ |
| 27 | 金手指状态 | 金手指是否被遗忘/滥用 |

### AI 痕迹检测（6 项，所有模式必检）— 含 novelize narrative rules

| 编号 | 维度 | 阈值 | 等级 |
|------|------|------|------|
| 28 | 段落等长 | 变异系数 < 0.15 | warning |
| 29 | 套话密度 | 模糊词>3次/千字（似乎/可能/或许） | warning |
| 30 | 公式化转折 | 转折词≥3次（然而/不过/与此同时） | warning |
| 31 | 列表式结构 | 连续相同开头句式≥3句 | info |
| 32 | AI标记词 | 「值得注意的是」「不可否认」等 | warning |
| 33 | **AI腔红线** | 章末升华/他感到直述情绪/连续2段纯心理/万能比喻/所有角色同声 | warning |

### 对话三功能检验（solo 模式必做）

每段对话删掉后检查：
1. 情节还能推进吗？
2. 期待感还在吗？
3. 情绪还到位吗？

三问皆否 → 该段对话可删或重写。

### 硬性禁令（3 项，所有模式必检）

| 编号 | 维度 | 说明 | 等级 |
|------|------|------|------|
| 34 | 破折号 | 正文中不得出现「——」 | blocking |
| 35 | 不是…而是… | 否定→肯定句式禁用 | blocking |
| 36 | 元叙事 | 「正如前文所述」等跳出句禁用 | blocking |

### full 模式追加（7 项）

| 编号 | 维度 | 说明 |
|------|------|------|
| 37 | 番外维度 | 番外正传冲突/信息泄露/规则一致性 |
| 38 | 情感弧线评估 | 全卷情感弧线是否递进 |
| 39 | 角色还原度 | 长篇角色是否随时间自然变化 |
| 40 | 场景描写评估 | 场景沉浸感 |
| 41 | 对话自然度 | 长时写作后对话风格是否漂移 |
| 42 | 同人维度（按需） | 角色还原/世界规则/正典事件 |
| 43 | 跨卷一致性 | 前后卷设定/风格一致性 |

## solo 模式执行流程

### Step 1：读取目标章节

```python
import os

project_root = "."
ch = input("章节号：")
ch_path = os.path.join(project_root, "chapters", f"ch_{ch:03d}.md")
if not os.path.exists(ch_path):
    # 兼容旧中文结构，实际执行时按文件搜索定位 chNN 或 第NN章
    ch_path = os.path.join(project_root, "正文", f"ch{int(ch):02d}.md")

if not os.path.exists(ch_path):
    print("ERROR: 该章节不存在")
    exit(1)

with open(ch_path, 'r', encoding='utf-8') as f:
    content = f.read()
```

### Step 2：执行维度检查

逐维度检查，记录结果。

### Step 3：输出审查报告

```markdown
# 第{N}章审查报告

- 模式：solo
- 审核章节：chapters/ch_{NNN}.md
- 字数：{N}
- 耗时：{N}

## blocking 问题（必须修复）
- [项数] [列表]

## warning 问题（建议修复）
- [项数] [列表]

## info 提示
- [项数] [列表]

## AI痕迹评分
- 段落等长：{pass/warning}
- 套话密度：{pass/warning}
- 公式化转折：{pass/warning}
- 列表式结构：{pass/warning}
- AI标记词：{pass/warning}

## 硬性禁令
- 破折号：{pass/FAIL}
- 不是…而是…：{pass/FAIL}
- 元叙事：{pass/FAIL}

## 总体评价
- 可发布：{yes/needs_revision}
```

## full 模式

当用于审查多章或全文时，优先使用 `delegate_task` spawn 子Agent 并行执行：

每个子Agent 加载对应 `agents/` 目录下的指令模板：

| Agent | 模板文件 | 职责维度组 | 模型建议 |
|-------|---------|-----------|---------|
| **story-architect** | `agents/story-architect.md` | 结构审查（维度 1-15）+ 全量追加（维度 37-43） | sonnet |
| **consistency-checker** | `agents/consistency-checker.md` | 事实/设定/伏笔审查（维度 16-27 含 AI腔红线） | haiku |
| **narrative-writer** | `agents/narrative-writer.md` | 文本/AI痕迹/硬禁令审查（维度 28-36 含对话三功能检验） | haiku |
| **character-designer** | `agents/character-designer.md` | 角色与对话审查（按需追加） | sonnet |

子Agent 只返回报告，主会话汇总。

每个子Agent 的 prompt 包含：审查范围（章节路径/项目根/设定文件列表）和审查级别。

如果 agent 不可用或 spawn 失败，不中断任务；降级为 lean/solo，并在报告开头说明降级原因。
