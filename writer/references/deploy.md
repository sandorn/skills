# 多卷部署流水线

> **节拍表模板 + 卷纲设计**：见 `plan.md`（总纲→卷纲→章纲）。本文件聚焦批量写章部署的执行层操作。

---

## 整体流程

```
总纲(暗线/反派分层/创意约束)
  ↓
第N卷 节拍表(8段结构)
  ↓
第N卷 详细大纲(60章事件线)
  ↓
├─ 审查:节拍表 vs 详细大纲 vs 总纲 (交叉校验)
├─ 写章: delegate_task 并行批量
↓
审查: 3轮循环 (详见 `references/review-cycle.md`)
↓
追踪文件更新 → 详见 `references/hooks-scan.md`
```

---

## 追踪文件更新

全卷或大批量写章后，必须更新 `追踪/伏笔.md`。详解见 `references/hooks-scan.md`。

**核心原则**：不逐章读全部N章。按**卷末章→已有伏笔章→重大事件章→前后5章→卷首章**的优先级，阅读约10-15%的章节即可覆盖95%伏笔。

## 节拍表8段模板

| 节拍 | 区间 | 爽点类型 |
|------|------|---------|
| 1.开篇钩子 | ch{N}-{N+6} | 能力/创业惊喜 |
| 2.第一轮小爽 | ch{N+7}-{N+17} | 先知红利/赚钱爽 |
| 3.冲突触发 | ch{N+18}-{N+27} | 压迫感/博弈 |
| 4.**中段反转** | ch{N+28}-{N+37} | **智谋取胜**(全书差异化) |
| 5.小高潮 | ch{N+38}-{N+47} | 双线高潮/名声 |
| 6.危机升级 | ch{N+48}-{N+52} | 极限施压 |
| 7.卷末高潮 | ch{N+53}-{N+56} | 终极反杀/收束 |
| 8.收尾+钩子 | ch{N+57}-{N+60} | 温情+新卷预告 |

每卷60章，中段反转必须体现"不靠武力靠智谋"的创意约束。

## 批量写章

### delegate批次

- **≤5章/批次安全** — 6+章大概率max_iterations退出
- 上下文: 提供大纲摘要+硬禁令+设定关键数据+前5章正文路径(声音内化)
- 写后三阶段修复必须由主会话执行

### 三阶段修复

```bash
# 阶段1: 破折号批量清零(无需读文件)
sed -i 's/——/，/g' chapters/ch*.md

# 阶段2: AI句式扫描+修复
grep -n '突然\|忽然\|他知道\|不是.*而是\|似乎\|仿佛' chapters/ch*.md
# 逐条 patch 替换

# 阶段3: 字数不足修复
# 用 execute_code 批量扫描,对不足章在末尾追加场景
```

## 卷间衔接检查清单

写完一卷进入下一卷前，必须验证跨卷衔接的 7 个维度：

| 维度 | 检查项 | 方法 |
|------|--------|------|
| **时间** | 上卷末章日期 vs 下卷首章日期 是否合理（≤1天跳跃或明确标注跳过时间） | 读末章末段 + 首章首段 |
| **情节** | 上卷钩子事件在下卷首章是否被承接（不悬空） | 核对末章钩子 → 首章前3段 |
| **等级** | 主角/核心角色等级是否连贯（无跳级或倒退） | 查角色状态卡 |
| **金币** | 金手指消耗是否跨卷可追溯（总额可加总） | 查资源账本 |
| **权限** | 权限等级 L0-L6 是否只在升级事件中变化 | 逐章核对权限变更点 |
| **角色位置** | 上卷末各角色物理位置/状态 → 下卷初是否延续 | 读角色状态卡 |
| **情感弧线** | 感情线关键节点是否被下卷继承（不重置） | 核对感情线里程碑 |

发现任意一个维度不一致 → **先修正大纲/设定**，再动笔写下卷。

## 卷末字数陷阱

每卷最后 5 章（ch{N+56}-{N+60}，收尾+钩子段）字数最难补足。原因：高潮已过、情节密度下降、收尾偏抒情。对策：
- 收尾章可以增加**角色独白/内心戏**（≥200字）来填充字数
- 钩子章扩展环境描写 + 新悬念的多角度铺垫（≥3个视角）
- 不建议在收尾段插入新情节线（会破坏卷末节奏）

## 批量写章前必做：总线对齐检查

每批写章前，执行预写总线对齐检查（详见 `references/pre-write-alignment.md`）：
1. 加载总纲/卷纲/章纲，确认当前写作位置与设计意图对齐
2. 读取追踪文件（角色状态/伏笔/章节摘要），确认状态连续
3. 交叉校验大纲 vs 追踪：角色等级、权限、金币、关系线是否衔接
4. 发现问题 → 修正大纲或追踪后再动笔
