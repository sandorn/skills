# 跨设定一致性审查指南

> 大纲/设定/卷纲之间的交叉校验方法。适用于项目审阅、开写前对齐、批量写章后复查。

---

## 审查维度

### 1. 设定文件内部一致性

| 检查项 | 涉及文件 | 常见问题 |
|--------|---------|---------|
| 具现触发规则 | story_bible + power_system | 同一规则在两处描述不一致 |
| 空间戒指容量 | story_bible + 各卷章纲 | 1立方米 vs 3立方米 |
| 属性百分比叠加 | power_system + 各卷章纲 | 某属性何时开始加的未说明 |
| 红卡碎片分类 | power_system + 各卷章纲 | 一次性规则碎片 vs 终极规则卡未区分 |
| 炼金工坊量产 | story_bible + power_system | 「唯一性」规则与炼金量产是否矛盾 |

### 2. 大纲与设定交叉

| 检查项 | 涉及文件 | 常见问题 |
|--------|---------|---------|
| 具现节点时序 | master_outline + 各卷章纲 | 章节编号与等级进度不对应 |
| 角色登场章节 | characters.md + 各卷章纲 | 角色在设定中写第X章登场，卷纲写第Y章 |
| 势力结构演化 | factions.md + 各卷章纲 | 卷纲事件与势力条目时间线冲突 |
| 核心资产追踪 | 各卷章纲 | 前一卷卷末资产 ≠ 后一卷卷初资产 |

### 3. 卷间衔接

| 检查项 | 涉及文件 | 常见问题 |
|--------|---------|---------|
| 等级连续性 | 相邻卷章纲 | 前一卷卷末等级 ≠ 后一卷卷初等级 |
| 资产继承 | 相邻卷章纲 | 药剂/装备/技能在各卷末状态不一致 |
| 角色认知边界 | characters.md + 相邻卷章纲 | 角色在某卷获知秘密，但下一卷仍装作不知 |
| 章节总数 | master_outline + 各卷章纲 | 各卷章节数之和 ≠ writer.json.chapters_total |
| 终章编号 | master_outline + 最后一卷章纲 | 总纲写第500章终，最后一卷写到第470章 |

### 4. 角色设定一致性

| 检查项 | 常见问题 |
|--------|---------|
| 年龄/身份 | characters.md 与卷纲中的描述是否一致 |
| 认知边界 | 每个角色是否都标注了「对秘密的认知」 |
| 跨卷追踪 | 角色在各卷的发展是否符合人物弧光 |
| 性别/称呼 | 同一角色在不同文件中称呼是否统一（如唐敏/唐姐） |

---

## 审查流程

1. **读取所有设定文件**：story_bible、characters、power_system、factions
2. **读取总纲**：master_outline
3. **逐卷读取章纲**：从第一卷到最后一卷
4. **逐项对照**：
   - 具现节点：总纲时间线 vs 各卷章纲具现设计 vs 卷纲细纲实际章节
   - 属性数值：每次具现后的属性叠加结果
   - 核心资产：每卷末资产清单 → 下一卷初是否一致
   - 角色登场：characters.md 初登场章节 vs 卷纲实际章节
   - 势力演化：factions.md 时间线 vs 卷纲事件
5. **输出报告**：按严重程度分级（🔴 阻塞 / 🟡 需确认 / 🟢 建议）

## 常见问题模式

### 模式 A：数值不一致
- **症状**：同一设定元素在不同文件中数值不同
- **根因**：后期修改未同步到所有文件
- **对策**：修改一处时，全局搜索所有引用并同步更新

### 模式 B：章节编号漂移
- **症状**：总纲写第X章发生某事件，卷纲写第Y章
- **根因**：卷纲拆分时章节编号重新编排
- **对策**：以卷章纲为准，总纲时间线需同步修订

### 模式 C：卷间资产断层
- **症状**：前一卷卷末有5瓶药剂，后一卷卷初变成3瓶，无交代
- **根因**：写章时消耗了药剂但大纲未更新
- **对策**：每卷结束时更新「核心资产状态」，下一卷开头引用

### 模式 D：角色认知倒退
- **症状**：角色在第100章知道了秘密，第120章却装作不知道
- **根因**：新增角色时未检查已有角色的认知状态
- **对策**：每个角色必须标注「对秘密的认知」，跨卷检查

---

## 适用场景

- 开写前：确保大纲和设定一致，避免写章时返工
- 批量写章后：检查已写章节是否与设定一致
- 卷间过渡：确认卷末资产/状态与下一卷卷初衔接
- 全面审查时：作为审查步骤0（项目体检）的一部分
