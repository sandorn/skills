# 番茄小说投稿格式兼容性检查清单

> 番茄小说是纯文本平台，不渲染 Markdown 格式标记。发布前必须清理所有可能污染读者阅读体验的格式残留。

---

## 必清项目（阻塞投稿）

### 1. Markdown 粗体/斜体标记

```
❌ **恭喜您升到22级。**          → 星号字面显示
❌ *互通成功。*                  → 星号字面显示
✅ 恭喜您升到22级。             → 纯文本
✅ 《雷电术》。                 → 书名号已足够标记
```

**扫描命令**：
```bash
grep -rn '\*\*[^*]\+\*\*' 正文/   # 粗体
grep -rn '(?<!\*)\*[^*\n]\+\*(?!\*)' 正文/   # 斜体
```

### 2. `#` 标题

```
❌ # ch001 — 重生               → 井号字面显示
✅ 第一章 重生                   → 或直接删除
```

番茄小说不支持 `#` 标题语法。保留章节标题内容但去掉 `#` 和 `chXXX` 前缀。

### 3. ASCII 双引号/弯引号

```
❌ "互通成功。"                  → 网文标准不用
❌ "互通成功。"                  → Unicode弯引号 U+201C/U+201D
✅ 「互通成功。」                → 必须使用
```

**扫描命令**：
```bash
grep -rn '"' 正文/ | grep -v '^[[:space:]]*#'    # ASCII引号
grep -rn $'\u201c\|\u201d' 正文/                  # 弯引号
```

### 4. 破折号

```
❌ 他站了起来——然后又坐下。    → 禁止
✅ 他站了起来。然后又坐下。     → 用句号断开
```

### 5. 段落长度

```
❌ 一段超过60个汉字             → 手机阅读体验差
✅ 每段≤60汉字，句号断段        → 番茄标准
```

### 6. 末句完整性

章末最后一句必须完整，不能截断。
```
❌ 他端起杯子喝了一口。水是     → 截断
✅ 他把杯子放回桌上。           → 完整
```

### 7. 其他 Markdown 标记

| 格式 | 番茄表现 | 修复 |
|------|---------|------|
| `_下划线_` | 显示字面下划线 | 删除标记 |
| `> 引用` | 不渲染 | 删除 `>` 前缀 |
| `[链接](url)` | 显示整段语法文本 | 删除或提取为纯文本 |
| `` `代码` `` | 显示反引号 | 删除反引号 |
| `<br>` `<hr>` | 显示字面 HTML | 删除 |
| `---` 分隔线 | 显示为横线文本 | 删除或用空行替代 |

## 可保留的格式

| 格式 | 说明 |
|------|------|
| `「」` 对话引号 | 网文标准格式，番茄完全支持 |
| 《》 书名号 | 技能书/书名标记，标准用法 |
| 空行分段 | 番茄按空行自然分段 |

## 建议项目（非阻塞）

### 字数
- 番茄推荐：2000-3000字/章
- 本书标准：≥2500字/章

### 数字列表
`1. xxx` `2. xxx` → 番茄平台可接受，无需转换

## 投稿前自动化检查脚本

```python
# fanqie_preflight.py
import re, os

BAN_MARKDOWN = [
    (r'\*\*[^*]+\*\*', 'Markdown粗体'),
    (r'(?<!\*)\*[^*\n]+\*(?!\*)', 'Markdown斜体'),
    (r'\"', 'ASCII引号'),
    (r'\u201c|\u201d', 'Unicode弯引号'),
    (r'——', '破折号'),
    (r'<[^>]*>', 'HTML标签'),
]

def check_fanqie_compat(dir_path):
    issues = []
    for f in sorted(os.listdir(dir_path)):
        if not f.endswith('.md'): continue
        path = os.path.join(dir_path, f)
        with open(path, 'r', encoding='utf-8') as fh:
            t = fh.read()
        for pat, name in BAN_MARKDOWN:
            if re.search(pat, t):
                issues.append(f'{f}: {name}')
    return issues
```
