# 网文开篇技巧

> 本文件涵盖多种类型的开篇技巧。重生文部分提炼自实战修改经验。

---

## 通用开篇原则（适用所有类型）

### 第一段法则

- **前 100 字必须建立钩子**：悬念/冲突/异常/期待感，四者至少有其一
- **第一句定调**：短句（≤15字）优于长句，动作优于描写，具体优于抽象
- **不解释世界观**：开篇让读者感受世界，不是理解世界

### 信息梯度

| 阶段 | 读者知道什么 | 为什么 |
|------|------------|--------|
| 前 500 字 | 主角的身份 + 当前困境/欲望 | 建立代入感 |
| 前 2000 字 | 世界的基本规则 + 第一个冲突 | 建立期待感 |
| 第一章结束 | 金手指出现（或暗示） + 本章钩子 | 建立追读欲 |

### 开篇避坑

| 坑 | 正确做法 |
|----|---------|
| 开头大段世界观说明 | 用角色的眼睛展示世界，不要用旁白讲 |
| 主角被动等待事件发生 | 主角必须主动做一件事，不管多小 |
| 第一章无冲突 | 最小的冲突也有张力（被人看不起/缺钱/时间紧迫） |
| 穿越/重生拖太久才穿 | 前 500 字内完成穿越/重生 |

## 重生文

### 死亡场景四原则

### 1. 年代质感正确
死亡场景必须对应当前年代，不能用过时的道具/环境。

| 错误（2029年死亡） | 正确 |
|------|------|
| 音像店放《心太软》（1996年的歌） | 隔壁刷短视频，一段音乐重复七八遍 |
| 吊扇吱呀吱呀响（90年代家电） | 空调外机嗡嗡转，车驶过路面 |
| 「前世四十六年」——人还没死就说「前世」 | 「四十六年」——死了才是前世 |

### 2. 主角不能是被动的
重生文的死亡不能是「糊里糊涂死了」。要给出一个**主动行为**的证据。

```
错误：落魄中年，出租屋孤独死，毫无来由地重生
正确：他知道时间到了。三年。解码。对齐。共振。能做的都做完了。
       → 他主动做过一件事，死亡是他等的结果
```

### 3. 死前暗示机制
死亡场景的最后一行，给出机制的暗示。不要解释，不要放设定说明。只需要**一行字**。

```
电扇停了。

一行字浮了出来。「通道已激活。目标：2001年9月28日。状态：等待接收。」

刘秋睁开眼睛。
```

原则：**暗示，不解释。一句，不展开。**

### 4. 重生后立刻连接
醒来后的第一反应，必须包含对死亡时那行字的回忆。不用长篇大论，一两句即可。

```
是太他妈高兴了。

然后他想起了最后一刻看到的东西。那行浮在意识深处的字。
他不完全明白那是什么。但他知道一件事——这不是意外。不是运气。
是有人做了什么事。把他送回了这里。
至于是谁做的。为什么。现在不急。
```

## 信息梯度设计

重生文的金手指来源不能一次性抖完。按以下梯度逐卷释放：

| 阶段 | 读者知道 | 主角知道 |
|------|---------|---------|
| ch01 | 死亡时有通道激活提示 | 有通道，不知详情 |
| ch02 | 系统面板出现「互通成功」 | 通道在工作，不追问来源 |
| ch180 | 手写体出现，对面有人在写字 | 是未来的自己在对话 |
| ch451+ | 39号实验室、中间层、共振频率 | 完整真相 |

## 金手指来源写法

### 不要「建造」

```
❌ 主角花三年造了一条跨时间通道
   → 落魄程序员怎么造的？说不通就崩了
```

### 要「激活」

```
✅ 通道是自然现象（39号实验室1970年代就在研究）
   主角只是找到了共振频率，对齐了时间窗口
   → 不需要解释建造能力，只需要解释发现
```

改动成本：约18处单词替换（建立→对齐/激活，建造者→对齐者），不涉及情节重写。

```
## 钩子开局 + 回忆穿插模式

### 适用场景

当项目大纲的前几章是线性铺垫（入坑→初入→首次刷金→等级提升→金手指），开局节奏偏慢时，可将开篇结构重构为：

**以金手指触发时刻为第一章开篇钩子**，将铺垫内容化为回忆穿插在主角的决策过程中。

### 操作步骤

1. 识别金手指首次触发点（如 20级弹窗、系统激活、穿越时刻）
2. 以此触发点为新第一章的第1段
3. 主角在决策/犹豫/分析的过程中，用回忆自然穿插原有铺垫内容
4. 回忆穿插控制：每段回忆不超过 3-5 句，服务于当前的决策逻辑

### 示例对比

| 旧结构（线性铺垫） | 新结构（钩子开局） |
|------------------|------------------|
| ch1: 最后一搏（查余额、找攻略、下载游戏） | ch1: 锚点（弹窗直接跳出，余额/攻略/下载全是回忆） |
| ch2: 初入旧神（新手村、低效打金） | ch2: 10%（身体变化验证，穿插过去的身体状态对比） |
| ch5: 弹窗才出现 | ch1 第1段就弹窗 |

### 关键原则

- 回忆不能是纯粹的信息堆砌，必须服务于**当前的决策逻辑**
- 比如：看体质卡 → 回忆自己身体多差 → 算投入产出比 → 决定选体质卡
- 原则：**每一个回忆片段都必须推动主角做出一个具体选择**

### 注意事项

- 此模式会导致章节数减少（从10章变6章），需同步更新卷纲/总纲中的所有章节引用
- 章节编号偏移时用**占位符单次替换**（先替换为 `__CH_N__`，再统一替换为最终编号），避免双重替换

## 主角性格方向决策框架

### 为什么需要显式决策

网文主角的性格不能是「模糊的好人」或「被动的承受者」。番茄小说平台的核心爽点来源之一是**主角的主动行为**——读者要看到主角驱动剧情，不是剧情推动主角。

### 三方向速查

| 方向 | 核心性格 | 决策模式 | 爽点来源 | 风险 |
|------|---------|---------|---------|------|
| **A. 精明果断型** | 穷但不蠢，每步都在算 | 三笔账（收益/策略/风险） | 智商碾压、步步领先 | 别写成龙傲天 |
| **B. 痞气韧劲型** | 底层混久了有痞气，嘴毒心热 | 能骂回去但也会忍，忍是为了翻盘 | 嘴炮爽、逆袭反差 | 分寸感是关键 |
| **C. 冷静疯批型** | 表面老实，内心极度冷静，敢赌 | 别人看不到的他看到，别人不敢的他敢 | 高智商博弈、暗线操控 | 笔力要求最高 |

### 方向 A（精明果断型）写作要点

- **弹窗出现 → 不是愣住，是辨认和分析**：第一反应永远是「这是什么？怎么用？投入产出比是多少？」
- **选择 → 算账驱动，不是情感驱动**：收益账（ROI）、策略账（长远布局）、风险账（暴露概率）
- **章末 → 行动决策，不是抒情**：不是「身体深处有什么在动」，而是「不打金了。全力冲级。」
- **对对手 → 分析对方的游戏规则**：不是讨厌老周，是分析「老周这种人不一定赢但一定活得久，对付他得比他更早算到下一步」
- **关键动词**：算、分析、判断、决定、布局。少用：感觉、觉得、似乎、仿佛。

### 方向 A 的声音特征

```
旧版（被动承受）：「张远愣住了。他玩这游戏两周了。」
新版（主动算计）：「张远的手指在鼠标上停了一秒。不是愣住，是在辨认。」

旧版：「他不知道自己怎么知道的。但他就是知道。」
新版：「10%。不是结局。是开局。」
```

核心转变：从「记录发生了什么」→「展示主角怎么算计接下来要发生什么」
❌ 46岁刘秋建造跨时间通道→代价是记忆→三个选项→最终选了…
✅ 重生2001年9月28日，传奇公测前夜。游戏装备可以带回现实。
   从一瓶小红药卖三百块开始。只讲钩子，不揭底。
```
