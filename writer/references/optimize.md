# 全量优化：钩子强度 + 爽点节奏

> **定位**：手工优化指南 + 辅助脚本扫描。目标的量化钩子/爽点指标，具体替换由作者或 AI 模型手工执行。不是全自动管线。
>
> **与其他管线的关系**：本文件专注「追读力」维度（钩子+爽点）。禁令/字数/段落修复见 `quality.md`，AI 批量润色见 `style-transfer.md`，纯手工精修见 `manual-polish.md`。

---

## 一、优化目标

1. **硬性禁令清零**：破折号、AI句式、元叙事等违规项全部清除（→ `quality.md` Step 1）
2. **意象钩子大幅降低**：将模糊意象表述替换为实体钩子，意象占比 ≤20%
3. **钩子强度提升**：平均钩子强度 ≥2.0/10，单章实体钩子 ≥3 个
4. **字数合规**：全章字数 ≥2500 汉字，段落 ≤60 字/段（→ `quality.md` Step 2）
5. **爽点节奏优化**：平均爽点数 ≥2.5/章

---

## 二、优化流程

```
1. 扫描 → analyze_hook.py 识别意象钩子章节 + 钩力分布
2. 替换 → 将意象类结尾手工替换为实体钩子（见下方钩子类型池）
3. 强化 → 为低钩力章节补充实体钩子
4. 爽点 → 为低爽点章节添加爽点元素
5. 终检 → audit.py 确认禁令清零 + analyze_hook.py 确认指标达标
```

## 三、工具命令

```bash
# 扫描钩子强度和爽点分布
python scripts/analyze_hook.py chapters/           # 全量
python scripts/analyze_hook.py chapters/ 1 60      # 指定范围

# 扫描禁令和字数

# 字数不足章补齐（内建段落拆分）
python scripts/pad_chapter.py --batch chapters/
```

## 四、实体钩子类型池（通用 — 无项目特定数据）

钩子强度从高到低排列。替换时应优先选择高强度类型。

### 1. 紧急危机（强度 ★★★★★）

特征：主角或亲密角色面临突然的、必须立即应对的危险。

```
模式：外部威胁突然出现 + 紧迫感
示例（通用）：
  - 手机响起，对面只说了一句话就挂了。声音很急。
  - 门被撞开。一群人冲了进来。
  - 警笛声越来越近，方向正是这边。
```

### 2. 倒计时（强度 ★★★★★）

特征：明确的时间压力，读者知道截止时间在逼近。

```
模式：时间锚点 + 未完成的任务
示例（通用）：
  - 距离事件发生还有 N 小时，所有人都在等。
  - 闹钟响了。距离见面还有三个小时。
  - 倒计时上的数字一直在跳。
```

### 3. 突然揭示（强度 ★★★★）

特征：读者和角色一起获得颠覆认知的新信息。

```
模式：发现关键信息 + 认知颠覆
示例（通用）：
  - 他翻到最后一页。上面有自己的名字，后面打了一个勾。
  - 来的人不是朋友。胸口挂着的工牌说明了一切。
  - 相框后面藏着另一张照片，日期是二十年前。
```

### 4. 未完成动作（强度 ★★★★）

特征：角色正在做某事但被中断，或动作悬在半途。

```
模式：动作开始 → 中断 → 留下悬念
示例（通用）：
  - 他刚拿起手机，还没来得及接，有人推开了门。
  - 手指已经按在发送键上。停了整整三秒。
  - 话说到一半。他忽然闭嘴了。
```

### 5. 离奇消失（强度 ★★★）

特征：人或物突然消失，留下不可解释的痕迹。

```
模式：存在 → 消失 + 残留线索
示例（通用）：
  - 刚才站在门口的人不见了。只留下一张纸条。
  - 桌上的东西消失了。抽屉也是空的。
  - 窗户开着。窗帘在风里晃。
```

### 6. 神秘线索（强度 ★★★）

特征：出现一个指向更大秘密的线索，但不揭示全貌。

```
模式：发现线索 + 暗示更大的谜团
示例（通用）：
  - 匿名短信。只有一个地址。
  - 桌角有一张旧纸条。上面写着几行代码。
  - 笔记本里夹着一张老照片。背面有字。
```

### 意象钩子识别（需要替换的）

以下类型的章末结尾属于「意象钩子」——用自然意象暗示情绪，读者无法形成具体期待：

```
特征：风/雨/雪/月光/夜色/路灯/影子 + 情绪暗示
应替换为：具体的事件钩子（危机/倒计时/揭示/未完成动作）

❌ 窗外的风还在吹。路灯把他的影子拉得很长。
❌ 雨停了。月光从云缝里漏出来。
✅ 手机亮了。一条短信，只有四个字。
```

## 五、爽点优化

### 爽点密度目标

| 指标 | 目标 | 检测方式 |
|------|------|---------|
| 平均爽点数 | ≥2.5/章 | `analyze_hook.py` |
| 微型爽点 | ≥1/千字 | 通读判断 |
| 中大型爽点 | ≥1/3千字 | 通读判断 |

### 爽点植入位置

- **章首 500 字**：回顾型微爽点（上次行动的余波/他人反应）
- **章中 60% 处**：主爽点（反转/碾压/突破）
- **章末 500 字**：钩子型爽点（预告/悬念）

### 常见场景的爽点模式

| 场景类型 | 爽点方向 | 强化手段 |
|---------|---------|---------|
| 战斗/对决 | 碾压感 | 对手震惊反应 + 围观者认知颠覆 |
| 财富/交易 | 数字冲击 | 从怀疑→震惊→畏惧的逐级反应 |
| 智力博弈 | 反制感 | 对手自信铺垫→被拆穿后的失态 |
| 身份揭晓 | 震撼感 | 多角度写不同人的反应 |
| 感情互动 | 情感回馈 | 小动作 + 内心独白 |
