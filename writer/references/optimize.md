# 全量优化模块（optimize.md）
> 用于网文全章节的意象钩子清理、钩子强度提升、质量优化，适配番茄小说投稿标准

---

## 一、优化目标
1.  **硬性禁令清零**：破折号、AI句式、元叙事、套路高频词等违规项全部清除
2.  **意象钩子大幅降低**：将非必要的模糊意象表述替换为实体钩子，占比≤20%
3.  **钩子强度提升**：平均钩子强度≥2.0/10，单章实体钩子≥3个
4.  **字数合规**：全章字数≥2500汉字，段落≤60字/段
5.  **爽点节奏优化**：平均爽点数≥2.5/章，符合爽文叙事节奏

---

## 二、优化流程
```
全量优化启动
    │
    ▼
1.  意象钩子识别：使用analyze_hook.py扫描全章节，标记意象钩子章节
    │
    ▼
2.  钩子替换：将意象类结尾替换为实体钩子（紧急危机/倒计时/突然揭示/未完成动作/离奇消失/神秘线索）
    │
    ▼
3.  钩子强度提升：为所有章节补充至少3个实体钩子，提升平均钩力
    │
    ▼
4.  爽点优化：为低爽点章节添加爽点元素（系统提示/剧情反转/商业突破/角色成长）
    │
    ▼
5.  终检：使用audit.py扫描全章节，确认硬性违规清零、字数合规
```

## 三、实体钩子池（高钩力，无意象）
### 1. 紧急危机类
> 手机突然炸了一样响起来。是赵凯打来的。声音很急：「秋哥，出事了！有人在网吧门口堵我们！」
> 门口传来急促的敲门声，没等他开门，哐当一声门被撞开了。老刀带着十几个兄弟冲了进来：「秋哥，深蓝的人来找麻烦了！」
> 外面忽然传来消防车的警笛声，越来越近，像是往秋海网城这个方向来的。

### 2. 倒计时类
> 离沙巴克攻城还有十二个小时，全行会的人都在等他上线，行会频道里全是刷「求老大快上线」的消息。
> 手机闹钟响了，距离和科技部领导的见面还有三个小时，他必须在半小时内赶到高铁站。
> 离高考放榜还有七天，林芷琪每天都在刷官网，手指都快磨出茧子了。

### 3. 突然揭示类
> 他忽然反应过来，刚才来的那个加盟商，口袋里露出的深蓝科技的工牌，他就是深蓝派来的卧底！
> 他翻到笔记本的最后一页，赫然写着自己的名字，后面跟着一个红勾，还有一行小字：「终于找到你了，秋海。」
> 林芷琪忽然抬起头，眼神坚定地看着他：「我知道通道的事，也知道你重生的秘密。」

### 4. 未完成动作类
> 他刚把手机拿起来，还没接，门被推开了，一个熟悉的身影站在门口：「方远，我找了你好久。」
> 他刚要把裁决之杖存进仓库，身后忽然有人拍了拍他的肩膀，一个低沉的声音响起：「这把武器，我要了。」
> 他刚要开口说话，林芷琪做了个噤声的手势，指了指窗外，一个黑影正在翻墙进入网吧。

### 5. 离奇消失类
> 等他再抬头的时候，刚才站在门口的那个人已经不见了，只留下一张纸条，上面写着：「沙巴克下有东西。」
> 桌上的裁决之杖模型忽然消失了，连个影子都没留下，抽屉里的笔记本也不见了踪影。
> 林芷琪刚刚还在隔壁房间，现在已经不见了，只留下半杯还冒着热气的牛奶。

### 6. 神秘线索类
> 手机收到一条匿名短信，只有一个地址和一句话：「我知道你的秘密，在沙巴克城下等你。」
> 他在桌角发现一张旧纸条，上面写着：「39号实验室，通道的秘密在那里。」
> 笔记本里夹着一张老照片，背面写着：「1992年，我们在一起。」

## 四、工具使用命令
### 1. 扫描意象钩子
```bash
python3 scripts/analyze_hook.py 正文/ --range 1-480
```

### 2. 全量审查（违规扫描）
```bash
python3 scripts/audit.py 正文/ --range 1-480
```

### 3. 补全字数
```bash
python3 scripts/pad_chapter.py --batch 正文/
```

### 4. 批量扫描钩子强度
```bash
python3 scripts/analyze_hook.py 正文/ --range 1-480
```

## 六、注意事项
1.  仅替换**非必要**的意象钩子，保留服务于剧情的必要意象
2.  实体钩子需贴合剧情场景，避免生硬插入
3.  优化后需重新运行全量审查，确认所有违规项清零
4.  数据库同步：使用codebase-memory-mcp工具将优化结果写入项目事实库
