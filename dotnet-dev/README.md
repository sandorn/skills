## 四套项目蓝图

1. **CLI 批处理工具**：文件整理、数据处理、接口调用
2. **WPF 桌面应用**：窗口、按钮、文件选择器、进度条
3. **Excel 批量处理**：用 ClosedXML 读写 Excel
4. **网页数据抓取**：HttpClient + HtmlAgilityPack
