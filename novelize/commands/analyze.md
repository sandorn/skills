# /novelize-analyze — 深度拆文分析

在扫榜基础上进行深度拆解，提取可借鉴的写作技法。

## 分析维度

| 维度 | 分析内容 |
|------|----------|
| 结构 | 卷级节奏、章节功能分布、高潮间隔 |
| 人物 | 角色关系网、出场频率、弧线设计 |
| 情节 | 反转类型统计、伏笔密度、爽点节奏 |
| 文风 | 句长分布、对话比例、描写密度 |
| 情绪 | 情绪弧线、章节情绪曲线、基调切换频率 |

## 输入
- 对标书目录（需已完成 /novelize-scan）
- 可选：分析深度（标准/深度）

## 执行
1. 读取拆文库中的已有数据
2. 调用 Agent(explorer) 加载对标书上下文
3. 主 session 按维度逐项分析
4. 生成深度拆解报告

## 输出
更新/生成：
- 拆文库/{书名}/拆文报告.md（追加深度分析章节）
- 拆文库/{书名}/_meta.json（更新分析状态）
