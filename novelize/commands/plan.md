# /novelize-plan — 大纲规划

从高到低三层规划：卷纲 → 章纲 → 细纲。

## 流程

### Step 1：卷纲
调用 Agent(architect) 生成全书卷级结构：
- 每卷目标、爽点节奏、情绪弧线
- 人物弧线、伏笔布局、关键反转

### Step 2：章纲
基于卷纲展开每章规划：
- 每章核心事件
- 开头钩子/章尾悬念
- 情绪起点→终点

### Step 3：细纲
逐章细化写作蓝图（可在写作过程中增量完成）：
- 具体情节点
- 关键对话方向
- 字数预估

## 输入
- 项目目录
- 可选：规划范围（全部/第X卷/第X-Y章）

## 输出
```
大纲/
├── 大纲.md          # 全书卷级结构
├── 卷纲_第1卷.md
├── 卷纲_第2卷.md
├── 细纲_第001章.md
├── 细纲_第002章.md
└── ...
```

## 必填项约束
卷纲必填：本卷目标 / 爽点节奏 / 情绪弧线 / 人物弧线 / 伏笔布局 / 关键反转
细纲必填：核心事件 / 开头钩子 / 爽点/情绪节点 / 悬念设置 / 情绪变化 / 涉及角色
