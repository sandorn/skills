# /novelize-init — 项目初始化

初始化网文写作项目，自动判定长篇/短篇模式。

## 判定逻辑
- 用户提供「书名 + 预计字数>10万字」→ 长篇模式
- 用户提供「书名 + 预计字数≤10万字」→ 短篇模式
- 未指定 → 询问用户

## 长篇模式输出
```
{书名}/
├── 设定/
│   ├── 世界观/
│   ├── 角色/
│   ├── 势力/
│   ├── 关系.md
│   └── 题材定位.md
├── 大纲/
├── 正文/
├── 追踪/
│   ├── 伏笔.md
│   ├── 时间线.md
│   └── 上下文.md
└── 参考资料/
```

## 短篇模式输出
```
{书名}/
├── 正文.md
├── 小节大纲.md
└── 设定.md
```

## 执行
1. 接收书名和基本信息
2. 调用 Agent(architect) 做题材定位初判
3. 按判定模式创建目录结构
4. 生成初始设定文件（使用 templates/ 模板）
