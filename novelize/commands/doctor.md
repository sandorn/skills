# /novelize-doctor — 项目体检

对写作项目进行全面的健康检查。

## 检查项

| 检查项 | 说明 |
|--------|------|
| 文件完整性 | 关键目录/文件是否存在 |
| 占位符扫描 | 是否有未填充的 TODO/占位符 |
| 备份状态 | 最近的备份时间 |
| 结构一致性 | 目录结构是否与模式匹配 |
| 设定完整性 | 角色/世界观文件是否齐全 |
| 大纲同步 | 大纲与实际章节数是否匹配 |
| 伏笔健康 | 活跃伏笔/已回收/已过期比例 |
| 禁令合规 | 全局禁令扫描 |
| 字数统计 | 全书/每卷/每章字数 |

## 诊断输出

```
=== Project Health Check: {书名} ===

[PASS] 目录结构完整
[PASS] 设定文件: 世界观 3个 / 角色 12个 / 势力 2个
[WARN] 大纲/卷纲_第3卷.md 缺失
[FAIL] 追踪/伏笔.md: 伏笔 F007 超期未回收 (第30章埋, 已过60章)
[INFO] 总字数: 152,300 (150章, 平均 1015字/章)
[INFO] 最近备份: 2026-06-15

=== Issues Found: 2 ===
1. [WARN] 大纲/卷纲_第3卷.md 缺失 → 运行 /novelize-plan 补充
2. [FAIL] 伏笔 F007 超期未回收 → 运行 /novelize-review 确认后处理
```

## 执行
1. 扫描项目目录结构
2. 检查所有关键文件
3. 运行 bin/ban-check.sh + bin/format-check.sh
4. 统计全书字数
5. 输出诊断报告

## 自动修复（可选）
```bash
/novelize-doctor --fix    # 自动修复可修复的问题（创建缺失文件、清理临时文件等）
```
