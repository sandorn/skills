# Outline Rules

大纲文件的规范。

## Rules

1. **卷纲必填项**：每个卷纲（卷纲_*.md）必须包含：
   - 本卷目标（主角在本卷结束时达到什么状态）
   - 爽点节奏（每 N 章一个大爽点）
   - 情绪弧线（本卷整体情绪走向）
   - 人物弧线（主要角色在本卷的成长/变化）
   - 伏笔布局（本卷埋设的伏笔及计划回收时间）
   - 关键反转（本卷至少一个关键反转）

2. **细纲必填项**：每个细纲（细纲_*.md）必须包含：
   - 本章核心事件
   - 开头钩子（用什么抓住读者）
   - 本章爽点/情绪节点
   - 悬念设置（章末留什么悬念）
   - 情绪变化（本章情绪起点→终点）
   - 涉及角色

3. **增量写入**：大纲必须增量写入——先写骨架，再逐节填充细节。

4. **与正文同步**：写完一章正文后，回头更新细纲中"实际完成情况"部分。

5. **章首钩子必须从规定类型选择**：悬念对话开局/闪前碎片/倒计时开局/神秘独白/反差场景/未完成动作开局/意象预示

6. **章尾钩子必须从规定类型选择**：突然揭示/紧急危机/未完成动作/身份反转/两难抉择/神秘物品·线索/倒计时/承诺·威胁/离奇消失/隐藏含义/意象钩子/回声钩子/留白钩子

7. **每章必须有情绪变化**：细纲必须标注情绪起点→终点，连续 2 章情绪无变化 = 需调整。
