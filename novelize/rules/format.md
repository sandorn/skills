# Format Rules

正文文件的格式规范。

## 绝对禁止

1. **禁止段落超过 60 字**：一句一段，每段不超过 60 个汉字（对话和内心独白除外）。
2. **禁止段落间空行**：正文段落之间不加空行，保持紧密节奏。
3. **禁止「他说」「她道」**：对话用动作代替对话标签。
4. **禁止大段描写堆砌**：描写必须穿插动作或对话，不连续超过 3 段纯描写。
5. **禁止跳出视角**：已确定视角（第一人称/限知第三人称）后，不切换到其他角色内心。

## 格式规范

- 对话独立成行，用冒号或动作引出
- 段落以情绪或动作为单位划分
- 章节标题用 `## 第X章 章名` 格式，标题后保留一个 Markdown 空行
- 正文段落之间不加空行
- 章节之间不使用 `---`、水平分隔线或额外空白行

## Examples

### Correct — 段落长度与一句一段
```
沈栀抬手，灵力从指尖涌出。
面前的结界出现一道裂缝，碎纹像蛛网般蔓延开。
她咬紧牙关加大输出，整条手臂开始发颤。
```

### Correct — 对话用动作引出（无「他说」）
```
沈栀将茶杯往桌上一顿。
"你到底想说什么？"
陆衍没接话，只是看着窗外。
```
