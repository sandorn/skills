# Skill — 技能管理

## 子类型

### 创建 Skill (skill-creator)
从零创建或改进 skill：定义触发词、工作流、工具权限。
触发：创建skill、new skill、improve skill

### 安装 Skill (skill-installer)
从 GitHub 或本地安装/更新/删除/信任 skill。
触发：安装skill、install skill、update skill

### 创建 Plugin (plugin-creator)
脚手架 DeepSeek plugin 目录和激活配置。
触发：创建plugin、package plugin

### 优化 (meta-optimize)
分析 ARIS 使用日志，优化 SKILL.md 和工作流默认值。
触发：优化技能、meta optimize、improve skills
