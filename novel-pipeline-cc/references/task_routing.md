# 任务自动分层路由表

> Layer 2 硬性执行规则。定义 Claude CLI 如何识别用户输入的任务类型，并路由到正确的处理链路。

---

## 路由决策树

```
用户输入
  │
  ├─ 包含 "世界观" "设定" "力量体系" "势力" "地图" "境界" → 【初始化设定】
  │     └─ 链路: Claude 引导用户填写 state-files/*.json → 无下游模型调用
  │
  ├─ 包含 "大纲" "章纲" "全书结构" "分卷" → 【大纲编排】
  │     └─ 链路: Claude 辅助规划大纲 → 写入项目章纲文件 → 无下游模型调用
  │
  ├─ 包含 "写" + 章节编号 或 "写第N章" → 【写单章正文】
  │     └─ 链路: DeepSeek 初稿 → 3轮自检 → [润色开关] → 豆包润色 → 输出
  │
  ├─ 包含 "重写" "修改第N章" "返工" → 【章节返工】
  │     └─ 链路: 读取现有章节 → 提取修改点 → DeepSeek(含修订指令) → 自检 → 输出
  │
  ├─ 包含 "润色" "文笔" "修饰" 且不涉及 "写" → 【独立润色】
  │     └─ 链路: 读取现有文本 → 直接豆包润色 → 输出
  │
  ├─ 包含 "批量" "连续" "第X-Y章" → 【批量生成】
  │     └─ 链路: 逐章循环【写单章正文】，每章完成后自动归档状态
  │
  ├─ 包含 "伏笔" "回收" "查伏笔" → 【伏笔审查】
  │     └─ 链路: 读取 foreshadowing.json → 生成伏笔状态报告 → 无下游模型调用
  │
  └─ 模糊输入 → 【澄清提示】
        └─ 链路: Claude 列出可能的任务类型，询问用户明确
```

---

## 各链路参数转换表

### 【写单章正文】参数准备

Claude 从 state-files 和用户输入中提取:

| 参数 | 来源 | 说明 |
|-----|------|------|
| `global_setting` | `world_setting.json` + `power_system.json` | 摘要：本章涉及的势力/地理/规则 |
| `chapter_outline` | 用户提供或分卷细纲文件 | 本章的具体剧情点列表 |
| `chapter_number` | 用户输入 | 解析 "第N章" |
| `revision_instructions` | 自动生成（自检失败时） | 初稿生成后自动填入 |

### 【独立润色】参数准备

| 参数 | 来源 | 说明 |
|-----|------|------|
| `chapter_characters` | `characters.json`（过滤本章出场角色） | 仅本章角色的状态摘要 |
| `chapter_mood_tone` | 用户指定或 Claude 从章节内容推断 | 六选一 |
| `draft_text` | 现有章节文件 | 完整文本 |

## 润色开关判定流程

```
章节大纲/文本
  │
  ├─ 过渡章节关键词命中 ≥ 3 个 → SKIP_POLISH=true
  │     关键词: 前往/赶路/飞行/传送/休整/采购/修炼日常/疗伤
  │
  ├─ 字数 < 1500 字 → SKIP_POLISH=true
  │
  ├─ 当前章节 ≤ 3 → SKIP_POLISH=true（前3章攒设定，建议后期统一润色）
  │
  └─ 其他 → SKIP_POLISH=false → 进入润色链路
```

用户可通过 `.env` 中的 `AUTO_SKIP_POLISH=false` 全局关闭自动跳过。

## 错误处理与降级策略

| 场景 | 处理 |
|-----|------|
| DeepSeek API 超时 | 重试 1 次 → 仍失败则降级为 Claude 直接生成短章 |
| 豆包 API 超时 | 跳过润色 → 输出 DeepSeek 初稿 + 标注 "未润色" |
| 3 轮自检连续 2 次失败 | 选最优版本 + 标注未解决问题 → 用户决策 |
| .env 未配置 API Key | 提示用户创建 .env 文件 → 提供 `.env.example` 内容 |
| state-files 不存在 | 提示用户先执行【初始化设定】→ 提供填写指南 |
| DeepSeek 返回非正文（含分析） | Hook 检测 → 在 check_draft_quality Round 3 中标记 → 重生成 |

## 复合任务拆分示例

**用户**: "帮我写第 10 章，写完顺便看看有没有需要回收的伏笔"

**Claude 识别**:
1. 主任务: 【写单章正文】→ 走完整流水线
2. 子任务: 【伏笔审查】→ 正文输出后附加伏笔状态报告

**执行顺序**: 先写章 → 归档 → 查伏笔 → 汇总输出
