## 跨项目影响

改了项目 A，检查项目 B 是否需要同步：
- B 调用 A 的 API → integration-guide 更新
- B 读取 A 的表 → Data Model 对齐
- B 依赖 A 的环境变量 → 环境变量表对齐
- B 部署依赖 A 的端口 → 端口表对齐
