# 评测用例

三个典型场景用于回归测试。

## 场景1：请示（典型场景）

**输入**: 起草一份向集团申请追加信息化预算的请示

**预期输出关键点**:
- [ ] 标题"关于申请追加XX年度信息化建设预算的请示"
- [ ] 一文一事
- [ ] 结尾"妥否，请批示"
- [ ] 含附件说明
- [ ] 含待确认事项

## 场景2：报告（边界场景 — 含多项汇报）

**输入**: 写一份上半年经营情况报告，包括营收、成本、项目进展三个板块

**预期输出关键点**:
- [ ] 标题"关于20XX年上半年经营情况的报告"
- [ ] 报告文种（结尾"以上报告如无不妥，请审阅"）
- [ ] 三个板块分节
- [ ] 不夹带请示事项
- [ ] 含待确认数据标注

## 场景3：错误纠正（错误路径）

**输入**: 帮我看看这份公文有什么问题：
> 关于申请项目立项的请示报告
> XX市发改委：
> 妥否，请批复。

**预期输出关键点**:
- [ ] 识别"请示报告"叠用
- [ ] 识别向不相隶属机关（发改委）用了请示
- [ ] 建议改为"函"，结尾"可否，请函复"
