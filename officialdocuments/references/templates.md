# 公文写作 — 模板库

> 词汇、句式、用语禁区等写作规范见 [`vocabulary.md`](vocabulary.md)。

## 一、请示

```markdown
# 关于XXX的请示

【主送机关】：

根据【依据文件/会议精神】，为【目的】，现就【事项】请示如下：

一、【请示理由】
（一）【理由1】
（二）【理由2】

二、【请示事项】
（一）【事项1】
（二）【事项2】

三、【建议方案】
【提供倾向性意见】

妥否，请批示。

附件：1.【附件名称】

【发文机关】
【发文日期】

## 待确认事项

- [ ] 【待确认项1】
```

```markdown

【主送机关】：

【引据段：概述背景、依据、总体评价】。现将有关情况报告如下：

一、【主要情况/成绩】
（一）【情况1】
（二）【情况2】

二、【存在问题】
（一）【问题1】
（二）【问题2】

三、【下一步打算】
（一）【打算1】
（二）【打算2】

以上报告如无不妥，请审阅。

附件：【如有附件，列明清单】

【发文机关】
【发文日期】

## 待确认事项

- [ ] 【待确认项1】
```

## 三、通知

```markdown
# 关于XXX的通知

【主送机关】：

为【目的】，根据【依据】，决定【事项】。现将有关事项通知如下：

一、【事项1】
（一）【具体内容】

二、【事项2】
（一）【具体内容】

三、【执行要求】
（一）【要求1】

特此通知。

附件：【如有附件】

【发文机关】
【发文日期】
```

### 会议通知补充要素

必须包含：会议时间、会议地点、参会人员、会议内容、有关要求（报名回执、请假程序）。

```markdown
一、现状与问题
（一）【现状1】
（二）【问题1】

二、具体建议
（一）【建议1】——【具体内容】——【可行性分析】
（二）【建议2】

三、预期效果
（一）【效果1】

以上建议请审阅。

【发文机关/部门】
【发文日期】
```

```markdown
【主送机关】：

一、【提示事项】
```

## 七、检查报告

```markdown
# 关于XXX的检查报告

【主送机关】：

根据【依据/工作安排】，检查组于【时间】对【被检查单位/事项】进行了【检查方式：现场检查/专项督导/综合检查】。现将有关情况报告如下：

一、检查基本情况
（一）检查时间：【起止时间】
（二）检查范围：【涵盖业务/部门/项目】
（三）检查方式：【听取汇报/查阅资料/现场核查/个别谈话】

二、检查发现的主要问题
（一）【问题领域1】。主要表现在：【具体表现】，不符合【依据文件/标准】第XX条要求。
（二）【问题领域2】。【具体表现】

三、整改意见
（一）针对【问题1】，建议【整改措施】，于【时限】前完成。
（二）针对【问题2】，建议【整改措施】，于【时限】前完成。

四、有关要求
（一）提高思想认识，高度重视检查发现问题整改工作。
（二）压实整改责任，逐项明确责任部门、责任人和完成时限。
（三）建立长效机制，举一反三，防止同类问题反复发生。
（四）请于【日期】前将整改情况报告及相关佐证材料报送【报送部门】。

【结尾用语：上行用"以上报告请审阅"，下行用"请按整改要求落实"】

附件：1.【问题清单】 2.【整改台账模板】

【发文机关/检查组】
【发文日期】

## 待确认事项

- [ ] 【待确认项1】
```

> 检查报告视为报告的专项变体。上行（向主管单位报告检查结果）结尾用"以上报告请审阅"；下行（对被检查单位提出整改要求）结尾用"请按整改要求落实"。
