# 公文写作 — 词汇库与写作规范

> 用语禁区（禁用词、标点、格式禁止）详见 [`errors.md`](errors.md) 速查表和 [`checklist.md`](checklist.md) 语言项。

## 一、词汇库

### 文种高频用语

| 文种 | 用语 |
|------|------|
| 请示 | 恳请批复、妥否请批示、如无不妥请批准 |
| 报告 | 以上报告如无不妥请审阅、特此报告、专此报告 |
| 通知 | 请认真贯彻执行、望遵照执行、特此通知 |
| 函 | 商请、盼复、请协助办理、特此函告、请予重视 |
| 建议书 | 以上建议请审阅、供参考、请研究 |
| 检查报告 | 请按整改要求落实、以上报告请审阅 |

### 国企改革与党建

| 领域 | 词汇 |
|------|------|
| 治理 | 党建入章、一肩挑、外大于内、应建尽建、四步工作法 |
| 改革 | 任期制和契约化、末等调整、不胜任退出、三能机制、破立并举 |
| 党建 | 双融共促、揭榜挂帅、把方向管大局保落实、定盘星、黏合剂 |
| 布局 | 资源重整、体系重构、制度重塑、主责主业、盘活存量 |

## 二、逻辑连接词

| 关系 | 推荐 | 备用 |
|------|------|------|
| 并列 | 一是……二是……三是…… | 一方面……另一方面…… |
| 递进 | 进而、从而、尤为重要的是 | 更为关键的是 |
| 转折 | 然而、但、尽管如此 | 但也要看到 |
| 因果 | 因此、故而、鉴于此 | 由此可见 |
| 让步 | 固然……但…… | 诚然 |
| 条件 | 只要……就……、只有……才…… | 以……为前提 |

> 一段内逻辑连接词不超过 3 种。

## 三、结构引导

| 位置 | 用语 | 场景 |
|------|------|------|
| 总起 | 总体来看、概括而言、核心在于 | 段落开头亮主旨 |
| 分述 | 具体而言、主要包括、突出表现在 | 展开论述 |
| 总结 | 综上所述、总的来看、实践证明 | 段落收束 |
| 过渡 | 与此同时、在此背景下、对此 | 段间衔接 |
| 强调 | 特别是、尤其是、当务之急是 | 突出重点 |

**段落规范**：`总—分—总` 或 `总—分` 框架；`一是……二是……` 分条；每条 3-5 行，不超过 8 行；先亮观点 → 再展开 → 回扣观点。

## 四、万能句式

| 主题 | 句式 |
|------|------|
| 目标 | 以XXXX为指引，紧紧围绕XXXX中心工作，以XXXX为主线，实现XXXX高质量发展 |
| 落实 | 压实主体责任，层层传导压力，形成一级抓一级、层层抓落实的工作格局 |
| 创新 | 唯改革者进，唯创新者强，唯改革创新者胜 |
| 作风 | 踏石留印、抓铁有痕 |
| 意义 | 事关全局、事关长远、事关根本；具有里程碑式意义 |
| 开局 | 开好局、起好步，实现"开门红""开门稳" |
| 收官 | 确保圆满收官、交出合格答卷 |
