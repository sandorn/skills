# 公文写作 — 模板库

## 一、请示

```markdown
# 关于XXX的请示

【主送机关】：

根据【依据文件/会议精神】，为【目的】，现就【事项】请示如下：

一、【请示理由】
（一）【理由1】
（二）【理由2】

二、【请示事项】
（一）【事项1】
（二）【事项2】

三、【建议方案】
【提供倾向性意见】

妥否，请批示。

附件：1.【附件名称】

【发文机关】
【发文日期】

## 待确认事项

- [ ] 【待确认项1】
```

## 三、通知

```markdown
# 关于XXX的通知

【主送机关】：

为【目的】，根据【依据】，决定【事项】。现将有关事项通知如下：

一、【事项1】
（一）【具体内容】

二、【事项2】
（一）【具体内容】

三、【执行要求】
（一）【要求1】

特此通知。

附件：【如有附件】

【发文机关】
【发文日期】
```

### 会议通知补充要素

必须包含：会议时间、会议地点、参会人员、会议内容、有关要求（报名回执、请假程序）。

## 七、词汇库

### 文种高频用语

| 文种 | 用语 |
|------|------|
| 请示 | 恳请批复、妥否请批示、如无不妥请批准 |
| 报告 | 以上报告如无不妥请审阅、特此报告、专此报告 |
| 通知 | 请认真贯彻执行、望遵照执行、特此通知 |
| 函 | 商请、盼复、请协助办理、特此函告、请予重视 |

|------|------|
| 治理 | 党建入章、一肩挑、外大于内、应建尽建、四步工作法 |

| 布局 | 资源重整、体系重构、制度重塑、主责主业、盘活存量 |

## 八、逻辑连接词

| 关系 | 推荐 | 备用 |
|------|------|------|
| 并列 | 一是……二是……三是…… | 一方面……另一方面…… |
| 递进 | 进而、从而、尤为重要的是 | 更为关键的是 |
| 转折 | 然而、但、尽管如此 | 但也要看到 |
| 因果 | 因此、故而、鉴于此 | 由此可见 |
| 让步 | 固然……但…… | 诚然 |
| 条件 | 只要……就……、只有……才…… | 以……为前提 |

> 一段内逻辑连接词不超过 3 种。

## 九、结构引导

| 位置 | 用语 | 场景 |
|------|------|------|
| 总起 | 总体来看、概括而言、核心在于 | 段落开头亮主旨 |
| 分述 | 具体而言、主要包括、突出表现在 | 展开论述 |
| 总结 | 综上所述、总的来看、实践证明 | 段落收束 |
| 过渡 | 与此同时、在此背景下、对此 | 段间衔接 |
| 强调 | 特别是、尤其是、当务之急是 | 突出重点 |

**段落规范**：`总—分—总` 或 `总—分` 框架；`一是……二是……` 分条；每条 3-5 行，不超过 8 行；先亮观点 → 再展开 → 回扣观点。

## 十一、用语禁区

### 禁用词汇

| 类别 | 禁词 | 替换 |
|------|------|------|
| 主观模糊 | "我觉得""大概""可能""差不多""众所周知" | 用数据或"XX"占位 |
| 口语化 | "哪怕""搞定""挺好""蛮多" | "即使""完成""良好""许多" |
| 情绪化 | "惊人""恐怖""令人发指" | 客观中立表述 |
| 网络用语 | "躺平""内卷""给力""点赞" | 不出现在红头文件中 |
| 文种混用 | "请示报告"叠用 | 择一 |
| 标点滥用 | 感叹号、反问句、设问句、省略号 | 陈述句 |

### 格式禁止

- 正文前加"好的""根据您的要求""以下是正文"等对话式前言
- 扩展解释、尾注、不必要的括号说明
- 议论、评价、夸张——文风朴实简练，记叙为主
- 编造数据——不确定的使用"XX"或"某月某日"占位
