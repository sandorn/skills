# 公文写作 — 发文前质量自检清单

逐项检查，勾选通过后方可定稿。

## 格式

- [ ] 标题、主送机关、正文、结尾、落款、日期六要素齐全
- [ ] 字体字号符合标准（标题二号小标宋、正文三号仿宋）
- [ ] 段落层次 `总—分—总` 清晰，条理分明
- [ ] 页边距、行距、页码规范

## 文种

- [ ] 文种与行文方向匹配（上行/下行/平行）
- [ ] 请示：一文一事、事前行文、结尾"妥否，请批示"
- [ ] 报告：陈述性，不夹带请示事项
- [ ] 通知：要素齐全（会议通知含时间/地点/人员/内容/要求）
- [ ] 函：对不相隶属机关，结尾正确
- [ ] 无"请示报告"叠用

## 内容

- [ ] 依据已列明或标注"待核实"
- [ ] 关键数据可追溯，标注来源
- [ ] 附件齐全，文件名、数量与正文一致
- [ ] 无编造数据——不确定项用"XX"占位

## 语言

- [ ] 无口语化表达（"搞定""挺好""蛮多"等）
- [ ] 无情绪化表达（"惊人""恐怖"等）
- [ ] 无模糊词（"大概""可能""差不多"等）
- [ ] 无网络用语（"躺平""内卷""给力"等）
- [ ] 单句长度适中（建议 ≤40 字）
- [ ] 无感叹号、反问句、设问句、省略号

## 逻辑

- [ ] 观点 → 事实 → 结论链条完整
- [ ] 因果关系清晰，无自相矛盾
- [ ] 数据前后一致（同一数据全文一致）
- [ ] 层级合理（一/（一）/1 递进规范）

## 政策合规

- [ ] 政策用语规范，对标集团/上级文件
- [ ] 无敏感措辞、无政治性表述错误
- [ ] 涉密信息已脱敏或已走加密流程

## 交付

- [ ] `## 待确认事项` 已列出，含负责人与时限
- [ ] 导出 docx/pdf 的文件名符合版本命名规范
- [ ] 修改记录完整（如有修改）
- [ ] 修改类文件的 `## 改动说明` 表已填写
