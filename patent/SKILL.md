# Patent — 专利申请

## 工作流

### 1. 发明构建 (invention-structuring)
将原始想法结构化：技术问题→解决方案→创新点→实施方式。
触发：构建发明、structure invention、发明构建

### 2. 现有技术检索 (prior-art-search)
专利数据库 + 学术文献检索。
触发：现有技术检索、prior art、专利检索

### 3. 可专利性评估 (patent-novelty-check)
评估新颖性和非显而易见性。
触发：专利查新、patent novelty、可专利性

### 4. 撰写权利要求 (claims-drafting)
独立/从属权利要求，多层次保护范围。
触发：撰写权利要求、draft claims

### 5. 撰写说明书 (specification-writing)
技术领域→背景→发明内容→附图说明→具体实施方式。
触发：撰写说明书、write specification

### 6. 实施例 (embodiment-description)
详细描述如何实施发明。
触发：撰写实施例、write embodiment、detailed description

### 7. 审查反馈 (patent-review)
外部专利审查员视角的审查意见。
触发：专利审查、patent review、审查意见

### 8. 格式化提交 (jurisdiction-format)
编译为 CN/US/EP 特定格式。
触发：格式转换、jurisdiction format、compile patent

## 全流程
使用 patent-pipeline 一键串联所有步骤：写专利全流程、draft patent
